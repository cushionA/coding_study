# ex03_holdout_score ヒント

## split_holdout

### tier1
「学習データの一部を隠して答え合わせに使う」という発想そのものは難しくない。
やることは「行の順番をシャッフルしてから、先頭何行かと残りに切り分ける」だけ。
「シャッフルしてから切る」ことと「決定的(何度呼んでも同じ結果)」であることの両立がポイント。

### tier2
DataFrame には行全体をランダムな順番に並べ替える操作がある(全体を1.0の割合で抜き出す、と考えると
「全部を抜き出すがシャッフルはされる」という動きになる)。乱数のシードを渡せる引数があるので、
それに `random_state` をそのまま渡せば同じ呼び出しは毎回同じ順番になる。
シャッフル後、`valid_frac` に応じた行数を `int(len(df) * valid_frac)` のように整数件数に直し、
先頭からその件数を検証側、残りを学習側に `.iloc` でスライスする。

### tier3
```python
n_valid = int(len(df) * valid_frac)
shuffled = df.sample(frac=..., random_state=...)   # frac=1.0 で全行をシャッフルするだけの並べ替えになる
valid_part = shuffled.iloc[:n_valid]
train_part = shuffled.iloc[n_valid:]
return train_part, valid_part
```

## category_median_baseline_score

### tier1
これは lesson でやった「カテゴリ別中央値 → 未知カテゴリは全体中央値に退避」と、やること自体はまったく同じ。
違いは「test」の代わりに「valid_part」を採点することと、最後に rmsle で数値化することだけ。

### tier2
`train_part.groupby(category_col)[target_col].median()` で「カテゴリ -> 中央値」の対応表(Series)ができる。
`valid_part` を1行ずつ見て、そのカテゴリが対応表の index に**含まれるか**を調べ、
含まれれば対応表の値、含まれなければ `train_part[target_col].median()`(全体の中央値)を使う。
含まれなかった件数を数えておく。最後に予測値の配列と `valid_part[target_col]` を、
この演習ファイルの冒頭にある `rmsle` に渡す。

### tier3
```python
medians = train_part.groupby(category_col)[target_col].median()
overall_median = float(train_part[target_col].median())

preds = []
n_unseen = 0
for cat in valid_part[category_col]:
    if cat in medians.index:
        preds.append(...)      # medians.loc[cat] を float で
    else:
        preds.append(overall_median)
        n_unseen += 1

score = rmsle(valid_part[target_col].to_numpy(dtype=float), np.array(preds, dtype=float))
return {"rmsle": ..., "n_unseen_category": ...}
```
