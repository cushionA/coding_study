# ex01_profile_and_sanity_check ヒント

## profile_columns

### tier1
lesson では `train.dtypes` / `train.isna().sum()` / `train.isna().mean()` / `train.describe()` を
それぞれ別々に print した。ここでは「1列につき、これらをまとめて1行にする」だけ。
やることは列を1つずつ見て、その列についての小さな情報の塊を作り、最後に全部まとめて表にする、という組み立て。

### tier2
`for col in df.columns:` で列名を1つずつ取り出し、`df[col]` でその列(Series)を得る。
列ごとに `{"dtype": ..., "n_missing": ..., ...}` という辞書を作り、`列名 -> 辞書` の対応表(辞書の辞書)を組み立てる。
数値列かどうかの判定には `pd.api.types.is_numeric_dtype(series)` が使える(True/Falseを返す)。
最後に `pd.DataFrame.from_dict(対応表, orient="index")` で「外側の辞書のキーがindexになる表」に変換できる。
列の並び順を指定通りにしたいときは、できた DataFrame を列名リストで選び直せば揃う。

### tier3
組み立ての骨格:

```python
rows = {}
for col in df.columns:
    s = df[col]
    is_numeric = pd.api.types.is_numeric_dtype(s)
    rows[col] = {
        "dtype": ...,          # str(s.dtype)
        "n_missing": ...,      # isna().sum() を int で
        "missing_rate": ...,   # isna().mean() を float で
        "n_unique": ...,       # nunique() を int で
        "min": ... if is_numeric and s.notna().any() else None,
        "max": ... if is_numeric and s.notna().any() else None,
    }
return pd.DataFrame.from_dict(rows, orient="index")[[...列名を指定の順で...]]
```

`min`/`max` の `...` は `s.min()` / `s.max()` を `float(...)` で包んだもの。
`None` は列を表に組み立てる過程で自動的に `NaN` になる(pandasの挙動)ので、テストでは `pd.isna(...)` で確認する。

## missing_rate_by_group

### tier1
lesson の概念3・④ でやった「for でカテゴリを回してマスクで絞る」のと同じ発想だが、
`for` を手で書く代わりに、pandas にはグループ分けそのものをやってくれる仕組みがある。

### tier2
`df.groupby(group_col)` は「group_col の値ごとにミニDataFrameへ分割してくれるイテレータ」を返す。
`for キー, サブ表 in df.groupby(group_col):` のように回せる(C#の `list.GroupBy(x => x.Key)` に近い)。
各サブ表に対して `.isna().mean()` を取れば、そのグループの欠損率になる。
group_col 自体に欠損があるグループも結果に含めたいなら、`groupby` にオプション引数を足す必要がある
(既定では欠損グループがまるごと消える)。

### tier3
```python
result = {}
for g, sub in df.groupby(group_col, dropna=...):   # dropna は False にする
    key_series = sub[...]                            # target_col の列
    result[g] = float(key_series.isna().mean())
return result
```
