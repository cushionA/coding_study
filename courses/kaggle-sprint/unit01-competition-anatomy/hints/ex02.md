## detect_alignment_issues

### tier1
lesson の概念3・⑤ でやった3つの突き合わせ(列の差分・dtypeの差分・カテゴリ集合の差分)を、
その場限りの print から「毎回呼べる関数」に変えるだけ。使う道具はどれも lesson で見た set の演算。

### tier2
- 列の差分は `set(train.columns) - set(test.columns)`(順序が保証されないので `sorted(...)` で揃える)。
- dtype の比較は、両方に存在する列だけを対象に、`str(train[c].dtype)` と `str(test[c].dtype)` を比べる。
- カテゴリの差分は、渡された `categorical_cols` の列それぞれについて
  `set(test[c].dropna()) - set(train[c].dropna())` を取る(lesson の `.isin` の逆方向にあたる考え方)。
  差が空集合の列は、結果の辞書に**キーごと入れない**(空リストを入れるのではない)。

### tier3

common_cols = [c for c in train.columns if c in test.columns]

## clean_data

### tier1
lesson の概念4・⑤ STEP1 で「重複削除 → price==0除外 → 桁違い除外」を順番にやり、
毎回 `shape` を print して確認した。ここでは4ステップ目(views<0の処理)を足し、
print する代わりに「記録をリストに積む」だけの違い。

### tier2
各ステップの前に `before = len(df)` を取っておき、操作後に `{"step": 名前, "rows_before": before, "rows_after": len(df)}`
を `log` リストに `append` する。重複削除は `item_id` を除いた列リストを `subset` に渡す
(lesson の概念3で使った `feature_cols` と同じ作り方)。
4番目の views の処理だけは「行を削除」ではなく「値を書き換える」ので、`df.loc[条件, "views"] = np.nan` を使う
(lesson の概念2・⑤ STEP5 でやった、代入は `.loc` を使う作法がそのまま活きる)。

### tier3
```python
log = []
feature_cols = [c for c in df.columns if c != "item_id"]

before = len(df)
df = df.drop_duplicates(subset=...)
log.append({"step": "remove_duplicates", "rows_before": before, "rows_after": len(df)})

before = len(df)
df = df[df["price"] ... 0]          # 0より大きい行だけ残す
log.append({"step": "remove_price_zero_or_negative", "rows_before": before, "rows_after": len(df)})

before = len(df)
df = df[df["price"] <= ...]         # 1_000_000
log.append({"step": "remove_price_outliers", "rows_before": before, "rows_after": len(df)})

before = len(df)
df = df.copy()
df.loc[df["views"] < 0, "views"] = ...   # np.nan
log.append({"step": "replace_negative_views", "rows_before": before, "rows_after": len(df)})

return df, log
```
