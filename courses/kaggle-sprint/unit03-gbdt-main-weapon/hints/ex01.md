# ex01_estimator_api ヒント

## fit_and_predict

### tier1
学習で状態が変わるので、受け取った実体ではなく複製へfitする。

### tier2
`sklearn.base.clone` は同じ設定の未学習estimatorを作る。複製へ `fit` してから `predict` する。

### tier3
`model = clone(estimator)`、`model.fit(...)` の順で呼び、modelとNumPy化した予測を返す。

## compare_parameter

### tier1
候補ごとにまっさらなモデルを作り直す。前候補の学習状態を持ち越さない。

### tier2
`clone(estimator).set_params(**{param_name: value})` で名前が変数でも設定できる。

### tier3
ループ内で複製・設定・fit・predict・`scorer(y_valid, pred)` を行い、`value -> float(score)` の辞書へ入れる。
