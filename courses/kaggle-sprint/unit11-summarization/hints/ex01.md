# ex01_extractive_centrality ヒント

## split / cosine

### tier1
文末記号の直後または改行で分ける。コサインは行正規化後の行列積。

### tier2
`re.split` のlookbehind、`np.linalg.norm(...,axis=1,keepdims=True)`。

### tier3
空白文を除き、正規化行列と転置の積を返す。

## centrality / select

### tier1
自己辺を消し、各行を確率にしてscoreを繰り返し流す。

### tier2
`score=(1-d)/n+d*transition.T@score`。上位位置はargsort。

### tier3
最後にscore和で正規化し、選んだindexを昇順へ戻して文を取る。
