# ex03 ヒント

## Tier 1

`T5Config` はencoder-decoderの設定です。batchでは入力のpadをattention対象外、正解のpadをloss対象外にします。モデルとtensorは同じdeviceへ置きます。

## Tier 2

attention mask は入力IDとpad IDの比較、loss無視値は `-100` です。labels付きforwardは `.loss` を返します。

## Tier 3

学習は勾配初期化→`model(**batch).loss`→逆伝播→更新です。生成は `generate` へ入力、mask、`max_new_tokens`、`num_beams` を渡します。
