# unit10: アンサンブルと推論パイプラインのコスト設計

このユニットを終えると、OOF予測をブレンド/stackingし、学習済み成果物を保存して再学習なしで推論し、LLM APIと自前推論の損益分岐を計算できる。

## なぜ学ぶか

コンペの最後は相関の低いモデルを組み合わせ、再現可能な提出へ固定する。実務ではさらに、学習と推論を分け、前処理・列順・閾値・バージョンを成果物として運ぶ必要がある。日次数万件では1件ごとのAPI課金と常時CPU推論の費用構造が違うため、数字で構成を選ぶことが上司へ予算を説明する材料になる。

学習はC#のビルド、artifactsはデプロイするバイナリと設定、推論はそれをロードして呼ぶ処理と考える。
