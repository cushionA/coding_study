# ex01_light_classifier ヒント

## build_vectorizer

### tier1
lesson の STEP 4 で書いたベクトル化器と同じものを、設定を引数から受け取る形にするだけ。
新しい API は1つも出てこない。「なぜその設定なのか」は概念②の箇条書きに戻ると書いてある。

### tier2
`HashingVectorizer(...)` をそのまま返す。渡す設定は4つ:

- 出力の次元(lesson では `2**18` を直接書いた)
- n-gram の範囲
- 分割の単位(`analyzer`。既定は単語だが、文字にもできる)
- 符号の交互付与を切る設定と、行ごとの正規化の設定

後ろ2つは lesson の概念②で説明したもの(`alternate_sign` / `norm`)。
`fit` は不要なので、作って `return` するだけでよい。

### tier3
```python
return HashingVectorizer(
    n_features=...,        # 引数をそのまま
    analyzer=...,
    ngram_range=...,
    alternate_sign=False,  # 非負にする
    norm=...,              # 各行の L2 ノルムを 1 にする指定
)
```

## fit_light_classifier

### tier1
lesson では `hv.transform(Xa)` で行列にしてから `SGDClassifier(...).fit(...)` した。
その2行を関数の中に入れて、学習済みの分類器を返すだけ。

### tier2
`vectorizer.transform(docs)` が疎行列を返す(`fit` は要らない)。
分類器は `SGDClassifier(loss="log_loss", ...)`。`alpha` / `max_iter` / `random_state` は
引数で受け取った値をそのまま渡す。`fit` は自分自身を返すので、
`clf = SGDClassifier(...); clf.fit(X, labels); return clf` でも
`return SGDClassifier(...).fit(X, labels)` でもよい。

### tier3
```python
X = vectorizer.transform(docs)
clf = SGDClassifier(loss=..., alpha=alpha, max_iter=max_iter, random_state=random_state)
...   # X と labels で学習させてから返す
```
`loss` は「対数損失」の指定(lesson でそのまま使った文字列)。

## evaluate_light_classifier

### tier1
やることは3つ: docs をベクトル化する / 予測する / 指標を2つ計算する。
`n_features` は新しく計算するものではなく、ベクトル化した行列がすでに持っている情報。

### tier2
`clf.predict(X)` で予測ラベルが得られる。
`accuracy_score(正解, 予測)` と `f1_score(正解, 予測, average=...)` の2つを使う。
多クラスでは `average` を指定しないとエラーになる。「クラスごとの F1 の単純平均」を表す指定は
lesson のチェックポイント A-2 のヒントに出ている。
行列の `shape` は `(行数, 列数) = (件数, 次元)` なので、次元はどちらの要素か確かめること。

### tier3
```python
X = vectorizer.transform(docs)
pred = clf.predict(X)
return {
    "accuracy": float(...),
    "macro_f1": float(f1_score(labels, pred, average=...)),
    "n_features": int(X.shape[...]),   # 列数のほう
}
```

## throughput

### tier1
lesson の STEP 3 / STEP 5 でやった測り方と同じ。
「前後で時刻を取って引き算し、件数で割る」だけ。

### tier2
`time.perf_counter()` が高精度な経過時間の測定に向いている(`time.time()` より粒度が細かい)。
`for x in items: fn(x)` で全件に適用し、その前後の差を経過秒とする。
返すのは「秒あたりの件数」なので、割り算の向きに注意(`経過秒 / 件数` は1件あたりの秒数)。

### tier3
```python
items = list(items)          # Series でも len が取れるようにしておくと安全
t0 = time.perf_counter()
for x in items:
    fn(x)
elapsed = ...
return float(...)            # 件数 ÷ 経過秒
```
