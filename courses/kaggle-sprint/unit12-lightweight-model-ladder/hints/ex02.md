# ex02_two_stage_matching ヒント

## candidate_pairs

### tier1
lesson の `candidate_recall` では `(min(i, j), max(i, j))` を集合に入れて重複を潰した。
今回は「上位k件」ではなく「閾値以上」なので、そもそも `i < j` の側だけを見れば重複は起きない。
行列の右上半分(上三角)だけを見る、という発想。

### tier2
やり方は2通りある。

1. 二重ループ: `for i in range(n): for j in range(i + 1, n):` として条件を満たすものを集める。
   40件程度なら十分速く、読みやすい。
2. NumPy: `np.triu(..., k=1)` で上三角のマスクを作り、閾値の条件と `&` で組み合わせてから
   `np.where(...)` で行番号・列番号を取り出す(既習のブールマスクがそのまま効く)。

`np.where` は行方向に走査するので、結果はもともと i の昇順・j の昇順で並ぶ。
返す要素は Python の `int` にしておくと、テストのタプル比較で余計な差が出ない。

### tier3
二重ループ版の骨格:
```python
s = np.asarray(sim_matrix, dtype=float)
out = []
for i in range(len(s)):
    for j in range(i + 1, len(s)):
        if ...:            # 類似度が閾値以上か
            out.append((i, j))
return out
```

## pair_stats

### tier1
4つの数のうち、3つは候補ペアの列挙結果から数えれば出る。
残る1つ(再現率)の分母だけが候補の外側 — **候補に入らなかった正例も含めた総数** — から来る。
lesson の C-4 のヒントに、その総数の出し方が書いてある。

### tier2
- 候補は `candidate_pairs` をそのまま呼べばよい(自分で書いた関数を使い回す)。
- 正例判定は `group_keys[i] == group_keys[j]`。`group_keys` はリストで渡ることもあるので
  `np.asarray(...)` で包んでおくと添字アクセスが安定する。
- 正例の総数は「グループのサイズ v ごとに `v*(v-1)//2` を足す」。
  グループのサイズは `pd.Series(group_keys).value_counts()` で得られる。
- 候補が0件のときに `n_positive / n_candidates` を計算すると `ZeroDivisionError` になる。
  0件なら 0.0 を返すよう先に分岐する。

### tier3
```python
pairs = candidate_pairs(sim_matrix, threshold)
n_pos = sum(1 for i, j in pairs if ...)
total_pos = int(sum(v * (v - 1) // 2 for v in pd.Series(...).value_counts()))
return {
    "n_candidates": len(pairs),
    "n_positive": n_pos,
    "recall": ...,          # 分母は total_pos
    "positive_rate": ... if pairs else 0.0,
}
```

## threshold_sweep

### tier1
`pair_stats` を閾値の数だけ呼んで、1行ずつ積み上げるだけ。
unit01 の `profile_columns` で「列ごとの辞書を集めて表にする」をやったのと同じ組み立て。

### tier2
辞書のリストを作って `pd.DataFrame(リスト)` に渡すと、辞書のキーが列になる。
`pair_stats` の戻り値の辞書に `threshold` のキーを足せば、必要な5列がそろう
(辞書の展開 `{"threshold": t, **stats}` が使える)。
列の並びを仕様どおりにしたいときは `pd.DataFrame(rows, columns=[...])` で明示する。

### tier3
```python
rows = []
for t in thresholds:
    stats = pair_stats(sim_matrix, group_keys, t)
    rows.append({"threshold": float(t), **stats})
return pd.DataFrame(rows, columns=[... 5つの列名 ...]).reset_index(drop=True)
```

## pick_threshold

### tier1
表から条件で行を絞る → 残りの中から1行選ぶ、という2段階。
unit01 でやった `df[条件]` のブールマスクがそのまま効く(条件が2つなので組み合わせる)。

### tier2
- 条件の組み合わせは `df[(条件A) & (条件B)]`。
  Python の `and` ではなく `&` を使い、各条件は括弧で囲む(演算子の優先順位のため)。
- 絞った結果が空かどうかは `len(絞った表) == 0` で分かる。空なら `raise ValueError("...")`。
  メッセージには「再現率の要求に届いていない」ことが分かる情報を入れる。
- 「候補数が最小の行」は `sort_values("n_candidates")` で並べ替えてから先頭を取るか、
  `idxmin()` で行の index を得てから引く。戻り値は `float(...)` で包む。

### tier3
```python
ok = sweep[(sweep["recall"] >= ...) & (sweep["n_candidates"] <= ...)]
if len(ok) == 0:
    raise ValueError(...)
return float(ok.sort_values(...).iloc[0][...])     # 先頭行の threshold
```
