# ex03_rule_vs_tagger ヒント

## detect_format

### tier1
やることは「3つの書式のどれに当てはまるか」を順に確かめるだけ。
ただし lesson で `newfmt` を作ったときの `str.match` は**先頭からの部分一致**で、
`A340-577` のような余分がある文字列も通してしまう。ここでは**全体**が一致しているかを見る必要がある。

### tier2
`re` には3種類の照合がある。用途を取り違えると上のような取りこぼしが出る。

| 関数 | 何をするか |
|---|---|
| `re.search(pat, s)` | 文字列のどこかに現れるか |
| `re.match(pat, s)` | 先頭から一致するか(末尾は自由) |
| `re.fullmatch(pat, s)` | 文字列全体が一致するか |

書式は 英字 `[A-Z]`、数字 `[0-9]`、繰り返し `{n}` の3つで書ける
(例: 英字2文字なら `[A-Z]{2}`)。
「書式名 → 正規表現」の対応をリストか辞書で持っておくと、for 文1つで回せて読みやすい。

### tier3
```python
patterns = [("A999-99", r"..."), ("AA-9999", r"..."), ("9999-AA", r"...")]
for name, pat in patterns:
    if re.fullmatch(pat, str(model_code)):
        return name
return ...
```
`A999-99` の正規表現は「英字1つ + 数字3つ + ハイフン + 数字2つ」をそのまま書き下したもの。

## rule_extract

### tier1
lesson の `rule_model` と骨格は同じで、違いは2つだけ。
正規表現が**1本ではなくリストで渡ってくる**ことと、ハイフンの復元が
**すでに `restore_hyphen` として用意されている**こと。

### tier2
- 全角を半角に揃えるのは `unicodedata.normalize("NFKC", ...)`(lesson の `rule_model` の1行目)。
  これをやらないと `Ａ３４０－５７` に正規表現が当たらない。
- `patterns` はコンパイル済みなので `pat.search(text)` の形で呼べる。
  見つかったときは `m.group(0)` が一致した文字列そのもの。
- 「先頭から順に試して、最初に当たったものを返す」= for の中で `return` してしまえばよい。
  ループを抜けたら `""` を返す。
- 返す前に `restore_hyphen(...)` を通すのを忘れないこと(ハイフンが落ちた綴りが3割ある)。

### tier3
```python
text = unicodedata.normalize(..., str(title))
for pat in patterns:
    m = pat.search(text)
    if m:
        return restore_hyphen(...)     # 一致した文字列を渡す
return ""
```

## exact_match_by_format

### tier1
「正解の書式」でグループ分けして、グループごとに件数と一致率を出す。
unit01 の `missing_rate_by_group` と同じ形で、グループのキーが列そのものではなく
**`detect_format` を通した結果**になっているだけ。

### tier2
組み立て方は2通り。

1. 一時的な DataFrame を作る: `{"fmt": 書式のリスト, "hit": 1.0/0.0 のリスト}` を作り、
   `df.groupby("fmt")["hit"].agg(["size", "mean"])` で件数と平均を同時に出す。
   `size` が件数、`mean` が一致率になるので、あとは列名を `["n", "exact_match"]` に付け替える。
2. 自分で辞書を組み立てて `pd.DataFrame.from_dict(..., orient="index")` にする(unit01 の ex01 と同じ)。

一致は「完全一致」なので `pred == gold` の真偽値をそのまま 1.0 / 0.0 として平均を取れば率になる。
index の並びは `sort_index()` で昇順にできる。

### tier3
```python
df = pd.DataFrame({
    "fmt": [detect_format(g) for g in golds],
    "hit": [... for p, g in zip(preds, golds)],   # 一致なら 1.0
})
out = df.groupby("fmt")["hit"].agg([...])
out.columns = ["n", "exact_match"]
return out.sort_index()
```

## compare_methods

### tier1
手法ごとに `exact_match_by_format` を呼べば、それぞれ「書式ごとの一致率」の列が得られる。
あとはそれを**手法が行・書式が列**になるように並べ替えるだけ。

### tier2
`{手法名: 一致率の Series}` という辞書を `pd.DataFrame(...)` に渡すと、
**辞書のキーが列**になる(index は書式)。求められているのは行と列が逆なので、
最後に転置する。転置は `.T`。
`.T` は NumPy の転置と同じ意味で、行と列の役割が入れ替わる — shape を print して確かめるとよい。

### tier3
```python
rows = {}
for name, preds in preds_by_method.items():
    table = exact_match_by_format(preds, golds)
    rows[name] = table["exact_match"]
return pd.DataFrame(rows)...        # 行=手法・列=書式 になるように向きを直す
```
