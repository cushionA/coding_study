# ex04_capstone ヒント

## train_linear_head

### tier1
logits→softmax→one-hotとの差がlogits勾配になる。

### tier2
`grad=(probabilities-one_hot)/n`、weight勾配は `X.T@grad`、biasは行sum。

### tier3
seed固定の小さいweightと0 biasを作り、steps回それぞれlr倍の勾配を引く。

## predict / choose / memory

### tier1
予測はlogits最大位置。小データ/低予算はfreeze、大データ・差大・高予算だけfull。

### tier2
`np.argmax(...,axis=1)`。メモリは全要素数×bytes。

### tier3
MiB変換は1024の二乗で割り、中間条件はstagedを返す。
