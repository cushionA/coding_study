# ex01 ヒント

## Tier 1

`Dataset` は C# の `IReadOnlyList<T>` に近く、件数と index 指定の取得方法を定義します。`DataLoader` は複数項目を自動でバッチ化します。

## Tier 2

`__len__` は path 数です。`__getitem__` では RGB 画像へ transform を適用し、`{"image": ..., "label": ...}` を返します。

## Tier 3

DataLoader には dataset と batch size に加え、shuffle と seed 済み `torch.Generator` を渡します。
