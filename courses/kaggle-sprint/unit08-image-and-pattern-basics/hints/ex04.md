# ex04 ヒント

## Tier 1

画像分類の古典 baseline は「augmentation→特徴量→group-aware OOF→誤分類ID確認」です。OOF は各行を、その行を学習に使わないモデルで予測します。

## Tier 2

左右反転は幅軸を逆順にします。HOG 前は gray 化します。fold ごとに train画像だけを拡張して特徴化し、valid画像は原画像のまま特徴化します。

## Tier 3

色 histogram はチャネルごとに合計1へします。`StratifiedGroupKFold.split` の train/valid index を拡張前に分け、`predict_proba(... )[:, 1]` を OOF 配列の valid 位置へ保存します。
