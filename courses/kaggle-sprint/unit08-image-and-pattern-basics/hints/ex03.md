# ex03_perceptual_hash_dedup ヒント

## average_hash

### tier1
色とサイズを揃えてから、各画素が全体平均以上かだけ残す。

### tier2
PILの `convert("L")` と `resize((hash_size,hash_size))`。

### tier3
float配列を平均と比較し、`reshape(-1)`。

## difference_hash

### tier1
dHashは平均ではなく、横に隣り合う画素のどちらが明るいかをbitにします。

### tier2
横を1画素多い幅へ縮小すると、右側と左側の同じ大きさの配列を作れます。

### tier3
`array[:, 1:]` と `array[:, :-1]` を比較して1次元へします。

## hamming_distance / near_duplicate_pairs

### tier1
bit列の異なる位置を数え、全index組合せへ適用する。

### tier2
`np.not_equal(...).sum()`。ペアはi<jだけ。

### tier3
二重rangeで距離が閾値以下のtupleをsetへ入れる。
