# ex02_collate_and_mask ヒント

## dynamic_pad

### tier1
batch内最長長さの2次元箱をpadで作り、有効部分だけ上書きする。

### tier2
`np.full` と `np.zeros_like`、各seqの `seq[:length]`。

### tier3
各行の先頭len(clipped)へIDを代入し、maskの同じ位置へ1を入れる。

## attention_bias / count_padding

### tier1
maskへ真ん中の軸を2つ足す。有効1は0、padding0は負値へする。

### tier2
`mask[:, None, None, :]` と `(1-mask)*-1e9`。pad数は比較結果のsum。

### tier3
float maskを4次元化して返し、countはintへ変換する。
