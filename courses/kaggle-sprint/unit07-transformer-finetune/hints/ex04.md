# ex04 ヒント

## Tier 1

`BertConfig` は C# の設定オブジェクト、`BertForSequenceClassification` はその設定から作る分類器です。学習更新後の重みを validation データで評価し、その値と同じ時点の state を保存します。

## Tier 2

モデル生成には `BertForSequenceClassification(config)` を使います。forward の返り値に `.loss` と `.logits` があり、loss に `backward()` を呼んでから optimizer を更新します。

## Tier 3

更新後に `eval()` と `inference_mode()` で validation loss を測り、改善時だけ state を複製します。予測は logits の最後の軸で最大位置を取ります。
