# ex02_table_parse ヒント

## get_headers

### tier1
theadの中にth要素が並んでいる。「theadの中のth」という祖先子孫の関係をセレクタで直接表現できる。

### tier2
`soup.select("thead th")` でth要素のリストを取得し、それぞれ `.get_text(strip=True)` でテキスト化してリスト内包表記でまとめる。

### tier3
```
return [th.get_text(strip=True) for th in soup.select("thead th")]
```

## get_rows

### tier1
tbody内には複数のtr(行)があり、各trの中に複数のtd(セル)がある。「行ごとにセルのリストを作り、それを行のリストとして集める」という二重構造になる。

### tier2
外側で `soup.select("tbody tr")` の各trについてループし、内側でその `tr.select("td")` からテキストのリストを作る。外側のループでリストに追加していく。

### tier3
```
rows = []
for tr in soup.select("tbody tr"):
    rows.append([td.get_text(strip=True) for td in tr.select("td")])
return rows
```

## rows_to_dicts

### tier1
「見出しのリスト」と「1行分の値のリスト」を対応する位置同士でペアにして辞書を作る、という操作にはPython組み込みの関数が向いている。

### tier2
`zip(headers, row)` は2つのリストを位置ごとにペアにするイテレータを作る。`dict(zip(...))` でそのまま辞書になる。これを各行についてリスト内包表記で繰り返す。

### tier3
```
return [dict(zip(headers, row)) for row in rows]
```
