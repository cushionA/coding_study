# ex03_records_cleanup ヒント

## get_item_name

### tier1
select_oneは要素が見つからなければ例外を投げずにNoneを返す。そのNoneに対していきなり.get_text()を呼ぶとエラーになる(C#のNullReferenceException相当)ので、先に見つかったかどうかを確認する必要がある。

### tier2
`item_tag.select_one(".item-name")` の結果をまず変数に受け取り、`is None` で分岐する。Noneなら"(名称不明)"を返し、そうでなければ`.get_text(strip=True)`を返す。

### tier3
```
name_tag = item_tag.select_one(".item-name")
if name_tag is None:
    return "(名称不明)"
return name_tag.get_text(strip=True)
```

## get_item_price

### tier1
get_item_nameとほぼ同じ形だが、欠損時に返す値が文字列ではなくNoneそのものである点が違う。

### tier2
`.item-price` を対象に同じNoneチェックのパターンを書く。見つからない場合の戻り値だけがNoneになる。

### tier3
```
price_tag = item_tag.select_one(".item-price")
if price_tag is None:
    return None
return price_tag.get_text(strip=True)
```

## collect_items

### tier1
"item item-featured"のように複数クラスを持つ要素も、CSSのクラスセレクタ `.item` は「itemクラスを含む要素すべて」にマッチするので特別扱いは不要。各itemに対してこのファイルの2つの関数を呼べば良い。

### tier2
`soup.select(".item")` で全li要素を取得し、各要素についてget_item_name/get_item_priceを呼んでname/priceキーの辞書を作り、リストに集める。

### tier3
```
result = []
for item_tag in soup.select(".item"):
    result.append({
        "name": get_item_name(item_tag),
        "price": get_item_price(item_tag),
    })
return result
```
