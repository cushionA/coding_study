## get_in_stock_products

### tier1
各商品カードについて、まず在庫の状態を確認し、「在庫あり」でなければスキップする。そのうえで名前と価格を取り出すが、価格は文字列のままではなく数値に変換する必要がある。文字列から特定の文字を取り除いてからint()に渡す。

### tier2
`soup.select(".product-card")` で各カードをループし、`.product-stock` のテキストが"在庫あり"かどうかで continue するかを決める。価格は `.product-price` のテキストから `.replace("円", "")` してから `int()` に渡す。

### tier3
```
result = []
for card in soup.select(".product-card"):
    stock = card.select_one(".product-stock").get_text(strip=True)
    if stock != "在庫あり":
        continue
    name = card.select_one(".product-name").get_text(strip=True)
    price = int(card.select_one(".product-price").get_text(strip=True).replace("円", ""))
    result.append({"name": name, "price": price})
return result
```

## total_sales

### tier1
表の各行から3列目(売上)のセルだけを取り出し、文字列を数値に変換しながら合計していく。列の位置はインデックスでアクセスできる。

### tier2
`soup.select("tbody tr")` で各行をループし、`tr.select("td")` で得たセルのリストの3番目(インデックス2)を `int()` に渡して積算する。

### tier3
```
total = 0
for tr in soup.select("tbody tr"):
    cells = tr.select("td")
    total += int(cells[2].get_text(strip=True))
return total
```

## count_complete_items

### tier1
ex03のget_item_name/get_item_price相当の考え方を、ここでは件数を数えるためだけに使う。名前用の要素と価格用の要素の両方が見つかった場合だけカウントを増やす。

### tier2
各itemについて `.item-name` と `.item-price` を `select_one` し、両方とも None でないときだけカウンタを+1する。

### tier3
```
count = 0
for item_tag in soup.select(".item"):
    name_tag = item_tag.select_one(".item-name")
    price_tag = item_tag.select_one(".item-price")
    if name_tag is not None and price_tag is not None:
        count += 1
return count
```
