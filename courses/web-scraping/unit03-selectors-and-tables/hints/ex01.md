# ex01_css_select ヒント

## get_all_product_names

### tier1
クラス名で複数の要素を一括で選び取りたいとき、find_allでタグ名とclass_引数を指定する方法もあるが、CSSセレクタ文字列1本で「このクラスを持つ要素すべて」を表す方法がある。C#でいうLINQのWhere一発に近い簡潔さ。

### tier2
`soup.select(セレクタ文字列)` はマッチした要素のリストを返す。クラス名を指定するセレクタは `.クラス名` の形。各要素からテキストを取り出すには `.get_text(strip=True)` を使う(前後の空白も除去できる)。

### tier3
```
return [tag.get_text(strip=True) for tag in soup.select(".product-name")]
```

## get_all_product_prices

### tier1
get_all_product_namesとほぼ同じ構造で、対象のクラス名だけが違う。

### tier2
`.product-price` を対象にした同じパターンのリスト内包表記を書く。

### tier3
```
return [tag.get_text(strip=True) for tag in soup.select(".product-price")]
```

## get_first_product_name

### tier1
複数ではなく「最初の1件だけ」が欲しいときは、リストの[0]を取るのではなく専用のメソッドがある。加えて、セレクタは半角スペースで区切ることで「祖先 子孫」の関係を表現できる。

### tier2
`soup.select_one(セレクタ)` は最初にマッチした1要素(無ければNone)を返す。`".product-grid .product-name"` のように空白で繋ぐと「product-gridの子孫にあるproduct-name」を意味する。

### tier3
```
tag = soup.select_one(".product-grid .product-name")
return tag.get_text(strip=True)
```
