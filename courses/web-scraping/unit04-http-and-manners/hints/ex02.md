# ex02_robots_check ヒント

## load_robots_parser

### tier1
`RobotFileParser` は本来 `rp.read()` でURLからrobots.txtを取得するが、それはネットワークアクセスになる。
ネットワークを使わずに同じ判定機能を使うには、テキストの中身を直接渡せる別のメソッドがある。

### tier2
`RobotFileParser` には `parse(lines)` というメソッドがあり、robots.txtの各行を要素とするリストを渡すとその内容でルールを構築できる。文字列を行のリストに変換するメソッドを思い出す。

### tier3
```
rp.parse(text.splitlines())
return rp
```

## is_allowed

### tier1
「このUser-Agentはこのパスを取得してよいか」を判定するメソッドが `RobotFileParser`自体に生えている。自分でDisallow行を読む必要はない。

### tier2
`rp.can_fetch(user_agent, path)` が真偽値を返す。

### tier3
```
return rp.can_fetch(user_agent, path)
```

## get_crawl_delay

### tier1
Crawl-delayが指定されていないUser-Agentも存在しうる。その場合にどう振る舞うべきかは呼び出し側が
`default` 引数で指定している。

### tier2
`rp.crawl_delay(user_agent)` はCrawl-delayの指定が無ければ `None` を返す。`None` かどうかで
`default` を使うか判定する。

### tier3
```
delay = rp.crawl_delay(user_agent)
return delay if delay is not None else default
```
