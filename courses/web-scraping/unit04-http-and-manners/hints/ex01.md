# ex01_parse_response ヒント

## get_body_if_ok

### tier1
成功したかどうかを表す真偽値のプロパティが response にあるので、それをそのまま条件分岐に使えばよい。

### tier2
`response.ok` が真のとき `response.text`、偽のとき `None` を返す三項的な書き方(条件式)ができる。

### tier3
```
return response.text if response.ok else None
```

## get_content_type

### tier1
辞書から「なければデフォルト値」で安全に取り出すメソッドをC#の `TryGetValue` の感覚で思い出す。

### tier2
`response.headers` は辞書なので `.get(キー, デフォルト値)` が使える。

### tier3
```
return response.headers.get("Content-Type", "unknown")
```

## count_by_status

### tier1
ex04(unit01)で書いたような「出現回数を数える辞書」と同じパターン。数えたいのは status_code の値。

### tier2
空の辞書から始めて、各 response の `status_code` をキーに `dict.get(key, 0) + 1` で加算していく。

### tier3
```
counts = {}
for response in responses:
    counts[response.status_code] = counts.get(response.status_code, 0) + 1
return counts
```

## get_body_or_raise

### tier1
「失敗なら例外を投げる」という処理そのものを担うメソッドが response に用意されている。自分でif文を書く必要はない。

### tier2
`response.raise_for_status()` を呼ぶと、失敗時は自動で例外が送出される(成功時は何も起きない)。呼んだ後に `text` を返せばよい。

### tier3
```
response.raise_for_status()
return response.text
```
