# ex01_string_extract ヒント

## clean_whitespace

### tier1
文字列の前後の余分な空白・改行を取り除く専用のメソッドが文字列型には最初から生えている。
C#の `string.Trim()` と同じ立ち位置。

### tier2
文字列オブジェクトの `.strip()` メソッドを使う。引数なしで前後の空白・改行をまとめて除去できる。

### tier3
`text.strip()` を返す。1行で完結する。

## split_tags

### tier1
「カンマで分割」と「各要素の前後空白を除く」は別々の操作。2段階に分けて考える。
C#の `Split` の後に `Select(s => s.Trim())` するのと同じ流れ。

### tier2
文字列の `.split(",")` でリストになる。そのリストの各要素に対して `.strip()` を適用する部分は、リスト内包表記で1行にまとめられる。

### tier3
```
return [part.strip() for part in text.split(...)]
```
`...` にはこの関数の引数(区切り文字)を入れる。

## extract_value

### tier1
「ラベル: 値」形式の文字列を分割する際、値の中に区切り文字と同じ文字が含まれていても
壊れないようにするには、分割回数を制限する必要がある。

### tier2
`.split(":", 1)` のように第2引数で分割回数を指定すると、最初の1回だけで区切って2要素のリストになる。得られた2要素目に対して前後の空白を除く処理を組み合わせる。

### tier3
```
_, value = text.split(":", 1)
return value.strip()
```

## format_summary

### tier1
複数の変数を埋め込んだ文字列を組み立てるには、C#の文字列補間 `$"..."` に相当する構文がPythonにもある。

### tier2
`f"..."` の中に `{変数名}` を書くと、その場で値が埋め込まれる。

### tier3
`f"名前: {name} / 職業: {job}"` を返す。
