# ex03_html_skim ヒント

## extract_between

### tier1
「あるタグの直後から次のタグの直前まで」を取り出すには、開始位置と終了位置をそれぞれ探して
文字列を切り出す。C#の `IndexOf` + 部分文字列取得に近い操作がPythonの文字列にもある。

### tier2
`.find(部分文字列)` は見つかった位置(インデックス)を返し、見つからなければ `-1` を返す。まず `start_tag` の位置を探し、それより後ろで `end_tag` の位置を探す(`.find` の第2引数で検索開始位置を指定できる)。両方の位置からスライス `html[a:b]` で切り出す。

### tier3
```
start_idx = html.find(start_tag)
if start_idx == -1:
    return None
start_idx += len(start_tag)
end_idx = html.find(end_tag, start_idx)
if end_idx == -1:
    return None
return html[start_idx:end_idx]
```

## extract_href_list

### tier1
1件だけなら extract_between に似た発想で取れるが、複数件を集めるには「見つけたら次の検索を
そこから先で再開する」というループが必要になる。

### tier2
`'href="'` を探す位置を毎回ずらしながら `.find(marker, search_from)` をループで呼ぶ。見つかった位置から次の `"` までがURL。ループを抜ける条件は `.find` が `-1` を返したとき。

### tier3
```
hrefs = []
marker = 'href="'
search_from = 0
while True:
    start_idx = html.find(marker, search_from)
    if start_idx == -1:
        break
    start_idx += len(marker)
    end_idx = html.find('"', start_idx)
    if end_idx == -1:
        break
    hrefs.append(html[start_idx:end_idx])
    search_from = end_idx + 1
return hrefs
```

## extract_paragraphs

### tier1
extract_href_list とほぼ同じ「ループで繰り返し検索」の構造。`<p>` と `</p>` のペアを1組ずつ
順番に探していく。

### tier2
`<p>` の開始位置を探し、そこから `</p>` の位置を探して中身を切り出す。切り出したら検索位置を `</p>` の後ろに進めて次のループへ。

### tier3
```
paragraphs = []
search_from = 0
while True:
    start_idx = html.find("<p>", search_from)
    if start_idx == -1:
        break
    start_idx += len("<p>")
    end_idx = html.find("</p>", start_idx)
    if end_idx == -1:
        break
    paragraphs.append(html[start_idx:end_idx])
    search_from = end_idx + len("</p>")
return paragraphs
```
