# ex02_list_dict ヒント

## long_words_upper

### tier1
「条件を満たす要素だけを変換する」は、ループを書かなくてもリストを1行で作れる構文がPythonにある。
C#の `Where().Select()` の連結を1つの式にまとめたようなもの。

### tier2
リスト内包表記 `[式 for 変数 in リスト if 条件]` を使う。「5文字以上」は `len(...)` で判定し、変換には文字列の大文字化メソッドを使う。

### tier3
```
return [w.upper() for w in words if len(w) >= ...]
```
`...` には「5文字以上」を表す比較式を入れる。

## count_tags

### tier1
出現回数を数えるには、「タグ名 → 回数」の対応を保持する入れ物が必要。C#の `Dictionary<string, int>` に相当するものがPythonにもある。

### tier2
空の辞書を用意し、タグを1つずつ見ながら「まだ辞書になければ0として扱い、1を足す」を繰り返す。辞書には「キーがなければデフォルト値を返す」メソッドがあり、それを使うとif文なしで書ける。

### tier3
```
counts = {}
for tag in tags:
    counts[tag] = counts.get(tag, 0) + 1
return counts
```

## most_common_tag

### tier1
辞書の項目(キーと値のペア)を「値の大きい順、同点はキーの昇順」で並べ替えれば、most番目を取り出すだけで済む。

### tier2
辞書の `.items()` で (キー, 値) のペア列が取れる。それを `sorted(...)` に渡し、`key=` 引数でソートの基準を「値は降順、キーは昇順」になるように組み立てる(値を負の数にすると降順にできる)。

### tier3
```
ordered = sorted(counts.items(), key=lambda item: (-item[1], item[0]))
return ordered[most - 1][0]
```
most は1始まりなのでインデックスは1つずらす。

## unique_tags

### tier1
「値が1のキーだけ」を集めるのは long_words_upper と同じ「条件を満たす要素だけ抽出」の発想。仕上げに並び替えが必要な点だけ異なる。

### tier2
`counts.items()` を内包表記でフィルタしてキーだけ集める。集めた後 `sorted(...)` に通せば昇順になる。

### tier3
```
return sorted(tag for tag, count in counts.items() if count == ...)
```
`...` には「ユニーク」を表す条件を入れる。
