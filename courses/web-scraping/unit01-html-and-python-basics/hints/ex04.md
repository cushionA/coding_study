# ex04_capstone ヒント

## parse_profile

### tier1
name/job/tagsの3つの行はどれも「ラベル: 値」の形をしているので、まず該当行のテキストを
タグに挟まれた部分として取り出し、それぞれからコロン以降の値を取り出す、という2段階の処理に
分解できる。tagsだけはさらにカンマ分割が必要。

### tier2
このファイル内の `extract_between` でHTML中の該当行を取り出し、`extract_value` でラベル部分を除いた値にする。tagsの値はさらに `split_tags` に通してリスト化する。3つの結果を辞書にまとめて返す。

### tier3
```
name_line = extract_between(html, 'class="name">', "</h2>")
job_line = extract_between(html, 'class="job">', "</p>")
tags_line = extract_between(html, 'class="tags">', "</p>")

name = extract_value(...)
job = extract_value(...)
tags = split_tags(extract_value(...))

return {"name": ..., "job": ..., "tags": ...}
```

## aggregate_tag_counts

### tier1
複数人分のタグを「1つの大きなタグのリスト」にまとめてしまえば、あとはこのファイルにある
タグ集計用のヘルパーがそのまま使える。

### tier2
リスト内包表記で各プロフィールの `"tags"` を1つのフラットなリストに展開する(リストのリストを1段階平坦化するイメージ)。展開したリストを `count_tags` に渡す。

### tier3
```
all_tags = [tag for profile in profiles for tag in profile["tags"]]
return count_tags(all_tags)
```

## format_profile_line

### tier1
辞書からname/job/tagsを取り出し、tagsはリストなので表示用に1つの文字列へ結合してから
全体をf-stringで組み立てる。

### tier2
リストをカンマ区切りの文字列に戻すには `", ".join(リスト)` を使う。結合した文字列と `profile["name"]` / `profile["job"]` をf-stringに埋め込む。

### tier3
```
tags_str = ", ".join(profile["tags"])
return f"{profile['name']}({profile['job']}) - タグ: {tags_str}"
```
