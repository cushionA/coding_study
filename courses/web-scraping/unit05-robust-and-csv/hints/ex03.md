# ex03_write_csv ヒント

## write_records_to_csv

### tier1
C#で `StreamWriter` をopenしてから `CsvWriter` に渡すのと同じ手順で、Pythonでも
「ファイルを開く→csvモジュールのWriterを作る→書く」の2段階になる。ファイルを開くときの
モードとエンコーディング指定を忘れると文字化けや改行の二重化が起きる。

### tier2
`open(path, "w", encoding="utf-8", newline="")` でファイルを開く(`newline=""` を忘れると
Windowsで改行が二重になる)。開いたファイルオブジェクトを `csv.DictWriter(f, fieldnames=...)`
に渡し、`writeheader()` でヘッダを書いてから `writerows(rows)` で本体を書く。

### tier3
```
with open(path, "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(rows)
```

## read_records_from_csv

### tier1
書き込みの逆で、`csv.DictReader` はヘッダ行を自動でキーとして扱ってくれる。1行1dictの
イテレータを返すので、リストに集める必要がある。

### tier2
`open(path, "r", encoding="utf-8", newline="")` で開き、`csv.DictReader(f)` を `list()` に
渡してすべての行を集める。

### tier3
```
with open(path, "r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    return list(reader)
```
