# ex01_clean_fields ヒント

## normalize_whitespace

### tier1
「前後の空白除去」と「内部の連続空白を1つにまとめる」は別の操作として考える。
C#では `Trim()` の後に正規表現 `Regex.Replace` で連続空白を潰すのに近い。全角スペース(`　`)も
「空白」として扱う必要がある点に注意。

### tier2
`str.strip()` は引数に取り除きたい文字集合を渡せる(全角スペースも含められる)。内部の連続空白は
正規表現 `re.sub` で「1個以上の空白(全角/半角)」を半角スペース1個に置換する。

### tier3
```
stripped = text.strip(" \t\n　")
return re.sub(r"[ 　]+", " ", stripped)
```

## parse_price

### tier1
数値に変換する前に、数字として解釈できない文字(通貨記号・カンマ)を全部取り除く必要がある。
C#の `decimal.Parse` の前に `Replace` で不要文字を除去する下処理と同じ発想。空/Noneのときは
例外を投げず、呼び出し側が判定しやすい値(None)を返す。

### tier2
`str.replace()` を複数回チェーンして `￥` `¥` `円` `,` を除去してから `int()` に渡す。空文字列や
Noneは早期リターンでNoneを返す。

### tier3
```
if not text:
    return None
cleaned = text.strip().replace("￥", "").replace("¥", "").replace("円", "").replace(",", "").strip()
if not cleaned:
    return None
return int(cleaned)
```

## normalize_date

### tier1
区切り文字が `/` `-` `年`/`月` とバラバラでも、「年・月・日の3つの数値を取り出す」という
構造は共通している。正規表現でこの3つをまとめて抜き出すのが素直。

### tier2
`re.match` で `(\d{4})` `(\d{1,2})` `(\d{1,2})` を区切り文字のクラス(`[/\-年]` など)を挟んで
1つのパターンにする。取り出した月日は `int()` に変換してから `:02d` でゼロ埋めしてf-stringに渡す。

### tier3
```
match = re.match(r"(\d{4})[/\-年](\d{1,2})[/\-月](\d{1,2})日?", text.strip())
year, month, day = match.groups()
return f"{int(year):04d}-{int(month):02d}-{int(day):02d}"
```
