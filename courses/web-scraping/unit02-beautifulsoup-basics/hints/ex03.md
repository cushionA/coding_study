# ex03_attributes ヒント

## get_floor_ids

### tier1
タグはPythonの辞書のように角括弧でアクセスすると属性値が取れる。まずは対象のタグを
find_allで全部集めてから、各タグの属性を取り出す発想。

### tier2
`find_all("div", class_="floor")` でタグのリストを取得し、各タグに対して
`tag["id"]` のように角括弧で属性値を取り出す(C#の `Dictionary` のインデクサに近い)。

### tier3
```
tags = soup.find_all("div", class_=...)
return [t[...] for t in tags]
```

## get_section_name

### tier1
「idで1件だけ探す」検索と「その中でさらに1件探す」検索を組み合わせる。
find()はタグに対しても呼べて、そのタグの子孫だけを対象に検索できる。

### tier2
`soup.find("div", id=section_id)` でidに一致するタグを取得する。取得したタグに対して
さらに `.find("span", class_="section-name")` を呼ぶと、そのタグの中だけを検索できる。
最後に `.get_text()` でテキストを取り出す。

### tier3
```
outer = soup.find("div", id=...)
inner = outer.find("span", class_=...)
return inner.get_text()
```

## get_next_section_id

### tier1
ツリー構造には親子関係だけでなく「同じ親を持つタグ同士(兄弟)」を辿る仕組みもある。
「次の兄弟を探す」ためのメソッドがあり、タグ名やクラス名で絞り込むこともできる。

### tier2
`tag.find_next_sibling("div", class_="section")` で、同じ階層にある次のsectionタグを
探せる。見つからない場合は `None` が返るので、そのまま返せば境界値も自然に処理できる。

### tier3
```
current = soup.find("div", id=...)
sibling = current.find_next_sibling("div", class_=...)
if sibling is None:
    return ...
return sibling[...]
```
