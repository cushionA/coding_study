# ex01_find_basic ヒント

## load_soup

### tier1
HTML文字列をただの文字列として扱うのはunit01までの話。ここではその文字列を
「タグのツリー」に変換してくれるオブジェクトが登場する。文字列を渡すと、
中身を解析済みのオブジェクトが返ってくるイメージ。

### tier2
`BeautifulSoup(html文字列, "html.parser")` の形で呼ぶ。`"html.parser"` は標準ライブラリ内蔵の
パーサ名で、外部ライブラリのインストールが要らない。

### tier3
```
parsed = BeautifulSoup(..., "html.parser")
return parsed
```

## get_title_text

### tier1
「タグを1つだけ探す」ためのメソッドがある。見つけたタグからテキスト部分だけを
取り出すメソッドも別に用意されている。C#で言えばXElement.Valueに近い。

### tier2
`soup.find("h1")` でタグを1つ取得できる。テキストを取り出すには `.get_text()` を使い、
前後の空白を除きたいときは引数 `strip=True` を渡せる。

### tier3
```
target = soup.find(...)
return target.get_text(...)
```

## get_first_tag_name

### tier1
「条件なしで検索する」と何が返るかを考える。見つけたタグは、自分が何というタグ名
だったかを覚えている(属性として持っている)。

### tier2
`soup.find()` を引数なしで呼ぶと最初のタグが返る。タグオブジェクトには `.name` という
属性がありタグ名の文字列が入っている。

### tier3
```
tag = soup.find()
return tag....
```
