# ex02_findall_loop ヒント

## get_all_link_texts

### tier1
findは1件しか返さないが、「条件に合う全部」を集めるための複数形のメソッドがある。
戻り値はタグのリストなので、そこから1つずつテキストを取り出す発想になる。
C#のLINQで言えば `Where(条件).Select(x => x.Text).ToList()` に近い。

### tier2
`soup.find_all("a")` はタグのリストを返す。リスト内包表記で各タグに `.get_text()` を
適用すれば、テキストのリストが作れる。

### tier3
```
tags = soup.find_all(...)
return [t.get_text() for t in ...]
```

## count_list_items

### tier1
「個数を数える」だけなら集めたリストの長さを見ればよい。

### tier2
`find_all("li")` で集めたリストに対して `len()` を使う。

### tier3
```
tags = soup.find_all(...)
return len(...)
```

## get_external_link_texts

### tier1
find_allにはタグ名だけでなく、class属性で絞り込むための追加引数がある。
C#で言えば `Where(x => x.ClassList.Contains("external"))` の絞り込みに相当する。

### tier2
`find_all("a", class_="external")` のように `class_` キーワード引数(Pythonの予約語
`class` と衝突するため末尾にアンダースコアがつく)を渡すと、そのクラス名を持つタグに
絞り込める。複数クラスが空白区切りで入っていても、その中に一致するクラス名があれば
ヒットする。

### tier3
```
tags = soup.find_all("a", class_=...)
return [t.get_text() for t in tags]
```
