# ex02_fetch_details ヒント

## parse_item_detail

### tier1
詳細ページには複数のフィールドがあり、それぞれ別のclass名を持つ単一要素として存在する
(一覧ページのように「複数件を探す」のではなく「各フィールドを1個ずつ探す」場面)。

### tier2
`soup.find(class_="...")` で各フィールドの要素を1つずつ取得し、`.get_text(strip=True)`で
前後の空白を取り除いたテキストにする。6個のフィールド分、同じパターンを繰り返すだけ。
辞書リテラルの中に直接書いてしまってよい。

### tier3
```
soup = BeautifulSoup(detail_html, "html.parser")
return {
    "name": soup.find(class_="item-name").get_text(strip=True),
    "price": soup.find(class_="item-price")...,
    ...(残り4フィールドも同様)
}
```

## fetch_all_item_details

### tier1
URLのリストを受け取って、1件ずつ同じ処理(取得→解析)を行い、結果を集める。
C#の`urls.Select(url => FetchAndParse(url)).ToList()`に相当する発想。

### tier2
空のリストを用意し、`item_urls`を`for`でループしながら`fetch`→`parse_item_detail`の結果を
`append`していく。ループの代わりにリスト内包表記で1行にまとめてもよい。

### tier3
```
results = []
for url in item_urls:
    html = fetch(url)
    results.append(parse_item_detail(html))
return results
```
