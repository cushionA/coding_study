# ex01_collect_links ヒント

## extract_item_links

### tier1
一覧ページの中には複数の商品カードがあり、それぞれにリンクが1つずつ付いている。
「同じclassを持つ要素を全部見つける」BeautifulSoupのAPIを使う場面。

### tier2
`soup.find_all("a", class_=...)` で該当するaタグを全部集められる。
各タグの`href`属性は辞書のように`tag["href"]`で取れるが、それは相対パス(`item_1.html`)なので、
そのままではURLとして使えない。BASE_URLと文字列結合する必要がある。

### tier3
`soup.find_all("a", class_="product-link")` で集めたタグそれぞれについて、
`BASE_URL + a["href"]` の形でリストに詰める。リスト内包表記1行で書ける。

## extract_next_page_url

### tier1
「次ページへのリンクがあるかもしれないし、無いかもしれない」状態を表すには、
値が無いことを表現できる型が必要。C#の`nullable`やLINQの`FirstOrDefault`に近い発想。

### tier2
`soup.find("a", class_=...)` は見つからなければ`None`を返す(`find_all`と違いリストにならない)。
`None`かどうかで分岐し、あればBASE_URLと連結、無ければそのまま`None`を返す。

### tier3
```
next_link = soup.find("a", class_="next-page")
if next_link is None:
    return None
return BASE_URL + next_link["...属性名..."]
```

## collect_all_item_links

### tier1
何ページあるか事前にはわからない。「次ページがある間続ける」ループの形が必要。
C#の`while (nextUrl != null) { ... }`と同じ構造。

### tier2
`current_url`を`start_url`で初期化し、`fetch`→`extract_item_links`で集めたリンクを
結果リストに追加(`extend`)、`extract_next_page_url`の戻り値を次の`current_url`にする。
`current_url`が`None`になったらループを終える。

### tier3
```
all_links = []
current_url = start_url
while current_url is not None:
    html = fetch(current_url)
    all_links.extend(...)
    current_url = extract_next_page_url(html)
return all_links
```
