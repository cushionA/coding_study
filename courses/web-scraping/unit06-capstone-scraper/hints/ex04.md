このcapstoneのextract_item_links / extract_next_page_url / parse_item_detail / strip_label /
price_to_int / clean_item / write_catalog_csv はex01〜ex03と同じ役割。
詰まったら`hints/ex01.md`〜`ex03.md`も参照してよい。ここでは新規部分だけを扱う。

## is_allowed

### tier1
robots.txtは「User-agentごとにDisallowされたパス」を書いたテキストで、標準ライブラリに
それを解析してcan_fetch判定してくれるパーサがある。ファイルやURLを直接読ませる設計だが、
今回は文字列(fetchで取得済み)から読み込みたい。

### tier2
`urllib.robotparser.RobotFileParser()`を作り、`.read()`(URLアクセスが走る)の代わりに
`.parse(行のリスト)`を使う。文字列を行のリストにするには`str.splitlines()`が使える。
判定には`.can_fetch(user_agent, url)`を使う。user_agentはこのファイル冒頭の定数を使う。

### tier3
```
rp = urllib.robotparser.RobotFileParser()
rp.parse(robots_txt.splitlines())
return rp.can_fetch(USER_AGENT, target_url)
```

## collect_all_item_links(start_url, sleep_fn)

### tier1
ex01と同じページ送りループだが、「次のページに進む前に一呼吸置く」礼儀(Crawl-delay)が
加わる。sleep_fnはtime.sleepそのものではなく、呼び出し回数をテストで確認できるように
差し替え可能な関数として渡されている。

### tier2
ループの構造はex01のcollect_all_item_linksと同じ。違いは、次ページが「ある」とわかった
タイミングで`sleep_fn()`を呼んでから`current_url`を更新すること(最後のページの後には
呼ばない=次が無いのに待つ必要はない)。

### tier3
```
next_url = extract_next_page_url(html)
if next_url is not None:
    sleep_fn()
current_url = next_url
```

## fetch_and_clean_all(item_urls, sleep_fn, crawl_delay, on_error=None)

### tier1
実務のスクレイパーは1件のページが壊れていても全体を止めてはいけない。
「その1件だけ諦めて次に進む」ための`try/except`と、失敗を記録する仕組みが要る。
C#で言えば`try/catch`しつつ`ILogger`にエラーを書いて処理を続けるパターン。

### tier2
`item_urls`を`enumerate(..., start=1)`でidを振りながらループする。各件で
`fetch`→`parse_item_detail`→`clean_item`を`try`ブロックに入れ、成功したら結果リストに
追加。`except Exception as exc:`で捕まえたら、`on_error`が渡されていれば
`on_error(url, exc)`を呼ぶ(渡されていなければ何もしない)。sleep_fnは成功・失敗に
関わらず1件処理するごとに呼ぶ(`finally`が使える)。

### tier3
```
results = []
for item_id, url in enumerate(item_urls, start=1):
    try:
        html = fetch(url)
        raw_item = parse_item_detail(html)
        results.append(clean_item(item_id, raw_item))
    except Exception as exc:
        if on_error is not None:
            on_error(url, exc)
    finally:
        sleep_fn(crawl_delay)
return results
```

## run_pipeline(start_url, output_path, sleep_fn, crawl_delay=1)

### tier1
これまでの全部品を正しい順番で並べるだけの「指揮者」関数。
①robots.txt確認 ②(許可されていれば)リンク収集 ③詳細取得+整形 ④CSV書き出し。
許可されていない場合でも「何も書き出さない」のではなく「空のCSV(ヘッダのみ)を書く」
という要求に注意する。

### tier2
`fetch(BASE_URL + "robots.txt")`でrobots.txtを取得し`is_allowed`で判定。
Falseなら`write_catalog_csv([], output_path)`して`[]`を返して終了。
Trueなら`collect_all_item_links`→`fetch_and_clean_all`→`write_catalog_csv`の順に呼び、
最後に整形済みリストを返す。`collect_all_item_links`のsleep_fnには
`crawl_delay`を渡す必要があるので、ラムダで包む(`lambda: sleep_fn(crawl_delay)`)。

### tier3
```
robots_txt = fetch(BASE_URL + "robots.txt")
if not is_allowed(robots_txt, start_url):
    write_catalog_csv([], output_path)
    return []

item_urls = collect_all_item_links(start_url, lambda: sleep_fn(crawl_delay))
rows = fetch_and_clean_all(item_urls, sleep_fn, crawl_delay)
write_catalog_csv(rows, output_path)
return rows
```
