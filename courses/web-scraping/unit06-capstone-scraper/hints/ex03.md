# ex03_pipeline_integrate ヒント

## strip_label

### tier1
"ラベル: 値" という決まった形の文字列から、コロンより右側だけを取り出したい。
コロンが無いケース(ラベルが付いていない値)も考慮する必要がある。

### tier2
文字列に`":"`が含まれるかは`in`演算子で判定できる。含まれる場合は`str.split(":", 1)`で
2分割し、右側の値だけ`.strip()`する。含まれない場合はそのまま(前後の空白だけ除去して)返す。

### tier3
```
if ":" in text:
    _, value = text.split(":", 1)
    return value.strip()
return text.strip()
```

## price_to_int

### tier1
"1200円"のような文字列から数値だけを残し、Pythonの`int`型に変換する。
C#の`int.Parse`の前に不要な文字を取り除く前処理が必要、というイメージ。

### tier2
`str.replace(old, new)`で"円"を空文字に置き換え、念のため桁区切りの","も同様に除去してから
`int(...)`に渡す。

### tier3
```
digits = price_text.replace("円", "").replace(",", "").strip()
return int(digits)
```

## clean_item

### tier1
生の辞書(ラベル付き・文字列のまま)を、最終的にCSVに書きたい形(数値化・ラベル除去済み)
に変換する。上で作った`strip_label`/`price_to_int`をここで組み合わせて使う。

### tier2
新しい辞書を作り、`id`は引数の`item_id`をそのまま、`name`/`stock`/`description`は
そのまま、`price`は`price_to_int`、`origin`/`roast`は`strip_label`を通した値を入れる。

### tier3
```
return {
    "id": item_id,
    "name": raw_item["name"],
    "price": price_to_int(raw_item["price"]),
    "origin": strip_label(raw_item["origin"]),
    "roast": strip_label(raw_item["roast"]),
    "stock": raw_item["stock"],
    "description": raw_item["description"],
}
```

## write_catalog_csv

### tier1
list[dict]をCSVファイルに書き出すには、辞書のキーをそのままヘッダ行として使える
標準ライブラリの機能がある。C#の`CsvHelper`の`WriteRecords`に近い。

### tier2
`csv.DictWriter(f, fieldnames=...)`を使う。`writeheader()`でヘッダ行を書き、
`rows`を1件ずつ`writerow()`する。ファイルを開くときは`newline=""`を指定しないと
Windowsで余計な空行が入ることがある(csvモジュールの公式推奨設定)。

### tier3
```
fieldnames = ["id", "name", "price", "origin", "roast", "stock", "description"]
with open(output_path, "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    for row in rows:
        writer.writerow(...)
```
