# 機械学習入門 (ml-intro)

Python と scikit-learn で、機械学習の基本ワークフローを一人で書けるようになるコース。

## コース目標

**CSVを読み込み、前処理し、scikit-learn でモデルを学習・評価するエンドツーエンドの流れを一人で書ける。**

## 「実務参加可能レベル」の定義

このコースを終えたとき、以下を他人の助けなしに一人で完結できる状態を指す。

- 表形式データ(CSV相当)を読み込み、pandas で中身を確認できる
- 欠損値の検出・補完、列選択、集計など基本的な前処理ができる
- `train_test_split` で学習用・検証用にデータを分けられる
- 回帰・分類のモデルを `fit` / `predict` で学習・推論できる
- 適切な指標(回帰: MAE/RMSE/R2、分類: accuracy/precision/recall/混同行列)でモデルを評価し、結果を解釈できる
- 上記を「読込 → 前処理 → 分割 → 学習 → 評価」の一連のパイプラインとして自力で組み立てられる

## 対象学習者

- C# 経験あり(AtCoder 茶色、OOP 理解あり)
- Python 経験は浅い
- 各ユニットで C# のアナロジー(配列/LINQ/インターフェース実装など)を用いて解説する

## 前提環境

- Python 3.13
- numpy 2.3.3 / pandas 2.3.3 / scikit-learn 1.8.0(インストール済み・追加インストール不要)
- 全課題は sklearn 組み込みデータセットまたはシード固定の合成データを使用。**外部ネットワーク不使用。**
