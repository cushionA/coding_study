# ex02_confusion_matrix ヒント

## prepare_and_train

### tier1
ex01でやった「読み込み→分割→学習」の流れをwineデータに対して繰り返すだけ。今回はモデルもまとめて返す点だけ違う。

### tier2
`load_wine()` の `.data`/`.target` を `train_test_split(test_size=0.2, random_state=42)` で分け、`LogisticRegression(max_iter=...)` を学習させる。wineは特徴量のスケールが大きいので `max_iter` はirisより多めに必要。

### tier3
```
wine = load_wine()
splits = train_test_split(wine.data, wine.target, test_size=..., random_state=...)
X_train, X_test, y_train, y_test = splits
clf = LogisticRegression(max_iter=...)
clf.fit(X_train, y_train)
return X_train, X_test, y_train, y_test, clf
```

## get_confusion_matrix

### tier1
「正解ラベルと予測ラベルのクロス集計」を1関数で作れる。自分で二重ループを書く必要はない。

### tier2
`model.predict(X_test)` で予測を作り、`confusion_matrix(正解, 予測)` に渡す。

### tier3
```
preds = model.predict(...)
return confusion_matrix(..., preds)
```

## get_precision_recall

### tier1
3クラス以上あるとき、precisionやrecallは「クラスごと」に計算されるので、平均する方法を指定する必要がある。

### tier2
`precision_score` / `recall_score` に `average="macro"` を渡すと、クラスごとの値を単純平均してくれる。

### tier3
```
preds = model.predict(...)
p = precision_score(..., preds, average=...)
r = recall_score(..., preds, average=...)
return p, r
```

## get_classification_report

### tier1
precision・recall・f1をクラスごとにまとめて見やすく整形してくれる関数がある。戻り値はそのまま印字できる文字列。

### tier2
`classification_report(正解, 予測)` を呼ぶだけ。

### tier3
```
preds = model.predict(...)
return classification_report(..., preds)
```
