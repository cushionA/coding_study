# ex01_train_classifier ヒント

## load_data

### tier1
irisデータは組み込みの読み込み関数1つで手に入る。読み込んだオブジェクトは「特徴量」と「ラベル」を別々の属性として持っている。

### tier2
`load_iris()` の戻り値には `.data`(特徴量)と `.target`(ラベル)という属性がある。

### tier3
`data = load_iris()` として `(data.data, data.target)` を返す。

## split_data

### tier1
「学習用とテスト用に分ける」専用の関数がscikit-learnにある。ループで自分で分割する必要はない。

### tier2
`train_test_split(X, y, test_size=..., random_state=42)` を使う。戻り値は4つで、順番は X_train, X_test, y_train, y_test。

### tier3
`return train_test_split(X, y, test_size=test_size, random_state=42)` とそのまま返せばよい。

## train_classifier

### tier1
分類モデルも回帰モデルと同じく「インスタンス化してfit」という2段階の手順で学習させる。

### tier2
`LogisticRegression(max_iter=...)` でインスタンスを作り、`.fit(X_train, y_train)` を呼ぶ。`max_iter` を大きめにしないと収束警告が出ることがある。

### tier3
```
clf = LogisticRegression(max_iter=...)
clf.fit(features_train, labels_train)
return clf
```

## evaluate_accuracy

### tier1
「予測してから正解と比べる」という2段階。予測結果と正解ラベルを比較する専用の関数がある。

### tier2
`model.predict(X_test)` で予測配列を作り、`accuracy_score(正解, 予測)` に渡す。引数の順番に注意。

### tier3
```
preds = model.predict(...)
return accuracy_score(..., preds)
```
