## train_and_score

### tier1
ex01の「学習」と「評価」を1つの関数にまとめる。モデルとaccuracyの両方を返す点に注意。

### tier2

clf = LogisticRegression(max_iter=...)

## cross_validated_accuracy

### tier1

### tier2

## most_confused_pair

### tier1
混同行列の対角線は「正解」なので、取り違えを探すには対角線を除外してから最大値を探す必要がある。

### tier2
`confusion_matrix` の結果をコピーし、対角線だけ0にしてから、行列内の最大値の「位置(行・列)」を求める関数を使う。行列の位置からインデックス(行番号・列番号)を取り出す関数がNumPyにある。

### tier3
```
cm = confusion_matrix(y_test, model.predict(...))
masked = cm.copy()
np.fill_diagonal(masked, ...)
r, c = np.unravel_index(np.argmax(masked), masked.shape)
return int(r), int(c), int(masked[r, c])
```
