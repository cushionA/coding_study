# ex03_cross_validation ヒント

## load_data

### tier1
ex01と全く同じ発想。irisを読み込んで特徴量とラベルを分けて返すだけ。

### tier2
`load_iris()` の `.data`/`.target` を返す。

### tier3
`data = load_iris()` として `(data.data, data.target)` を返す。

## cross_validate

### tier1
「学習と評価をK回繰り返して平均を取る」処理は1つの関数にまとまっている。fitを自分で複数回呼ぶ必要はない。

### tier2
`cross_val_score(モデル, X, y, cv=分割数)` を使う。モデルは学習前の(fitしていない)インスタンスを渡す。

### tier3
```
clf = LogisticRegression(max_iter=...)
return cross_val_score(clf, X, y, cv=...)
```

## summarize_scores

### tier1
配列の「平均」と「ばらつき」を表す統計量がそれぞれメソッドとして用意されている。

### tier2
NumPy配列には `.mean()` と `.std()` がある。

### tier3
`return scores.mean(), scores.std()`

## cross_validate_shuffled

### tier1
`cv` 引数には整数(分割数)だけでなく、分割方法そのものを表すオブジェクトを渡すこともできる。シャッフルするかどうかはそのオブジェクト側で指定する。

### tier2
`KFold(n_splits=..., shuffle=True, random_state=42)` で分割器を作り、それを `cross_val_score` の `cv` に渡す。

### tier3
```
splitter = KFold(n_splits=..., shuffle=..., random_state=...)
clf = LogisticRegression(max_iter=...)
return cross_val_score(clf, X, y, cv=splitter)
```
