# unit01: NumPy配列の基本

このユニットを終えると、ループを書かずに配列全体への数値演算ができるようになる。
これは pandas・scikit-learn すべての土台になる。

## なぜ学ぶか

実務のデータ処理は「100万行の数値を一括変換する」「条件で絞り込む」「行・列ごとに集計する」の繰り返しで、Python の素のループでは遅すぎて使いものにならない。データを扱う現場のコードはほぼ例外なく NumPy 配列演算で書かれており、これが読めない・書けないと pandas 以降のコードレビューにも参加できない。求人票の「NumPy/pandasでのデータ処理経験」の中身がこのユニットである。

## 概念: NumPy配列とC#配列の違い

- C#の `int[]` は要素ごとにループで処理するが、NumPy配列は `arr * 2` のように**配列全体への演算**が基本。内部はC実装なのでループより桁違いに速い。
- 型は全要素で共通(`dtype`)。C#のジェネリクス `T[]` に近く、`List<object>` 的な混在はしない。
- 条件抽出は `arr[arr > 3]` のように「真偽値の配列(ブールマスク)を添字にする」。C#の `arr.Where(x => x > 3)` に相当するが、ループもラムダも書かない。
- 形状(shape)の異なる配列同士でも、NumPyが自動でサイズを揃えて演算する(ブロードキャスト)。行列 + ベクトル、のような処理がループなしで書ける。
