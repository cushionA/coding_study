# ex02_masking ヒント

## filter_greater_than

### tier1
「条件を満たす要素だけ取り出す」には、まず配列と同じ長さの真偽値の並びを作り、それを添字として使う。C#の `Where` に相当するが、NumPyでは「条件式そのものが真偽値の配列になる」という発想が先にある。

### tier2
`arr > threshold` は真偽値の配列(ブールマスク)を返す。`arr[マスク]` と書くとマスクが `True` の位置の要素だけが残る。

### tier3
`arr[arr > threshold]` を返す。比較演算子がそのままマスク生成に使える。

## filter_even

### tier1
「偶数かどうか」は割り算の余りで判定できる。ここでもマスクの発想を使う。

### tier2
`arr % 2 == 0` でブールマスクを作り、`filter_greater_than` と同じように添字に使う。

### tier3
`arr[arr % 2 == 0]` を返す。

## clip_below

### tier1
「一部の要素だけ書き換えて、元の配列は壊さない」には、まずコピーを作ってから書き換える必要がある。NumPy配列の代入操作は元の配列を直接変更する(参照渡し)ことを思い出す。

### tier2
`arr.copy()` で複製を作る。複製に対して `result[マスク] = value` の形でマスク位置だけ代入できる。

### tier3
```
result = arr.copy()
result[result < threshold] = ...
return result
```

## count_matching

### tier1
ブールマスクの中身(True/False)は、数値として扱うと何になるか考える。合計を取ると何が求まるか。

### tier2
`True` は 1、`False` は 0 として扱われるため、マスクの `.sum()` が「条件を満たす個数」になる。

### tier3
`int((arr > threshold).sum())` を返す。
