# ex04_capstone ヒント

## make_scores

### tier1
「シード固定の乱数」は、乱数生成器そのものをシード付きで作ってから、そこに整数生成を依頼する2段階の手順になる。

### tier2
`np.random.default_rng(seed)` で生成器を作る。生成器の `integers(low, high, size)` メソッドで指定した形状の整数配列を作れる。`high` は含まれない点に注意。

### tier3
```
rng = np.random.default_rng(seed)
return rng.integers(0, 101, size=(...))
```
size にはタプルで (生徒数, 科目数) を渡す。

## student_averages

### tier1
「行ごとの平均」は ex03 で使った軸指定の考え方がそのまま使える。生徒が行、科目が列であることを思い出す。

### tier2
`scores.mean(axis=...)` でどちらの軸を平均すれば「各生徒の全科目平均」になるか考える。

### tier3
`scores.mean(axis=1)` を返す。

## count_passing

### tier1
「平均点で合格者数を数える」は、まず平均点の配列を作り、それに対して ex02 の `count_matching` と同じ発想を適用する。

### tier2
`student_averages` 関数(この課題内で定義済み)を再利用できる。得られた平均点の配列に `>= threshold` のマスクをかけて合計する。

### tier3
```
averages = student_averages(scores)
return int((averages >= threshold).sum())
```

## curve_by_subject

### tier1
「科目ごとの平均を引く」は ex03 の `center_columns` と全く同じ構造。どの軸が「科目」に対応するか確認する。

### tier2
列(科目)ごとの平均は `axis=0` で取れる。それを元の得点表から引くとブロードキャストされる。

### tier3
`scores - scores.mean(axis=0)` を返す。
