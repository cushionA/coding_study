# ex03_broadcasting ヒント

## add_row_vector

### tier1
形状 `(rows, cols)` の行列と形状 `(cols,)` のベクトルは、サイズが違ってもそのまま演算できる。NumPyが自動で「足りない次元」を埋めてくれる。

### tier2
`+` 演算子をそのまま使うだけでよい。ループで行ごとに足す必要はない。

### tier3
`matrix + vector` を返す。これだけでベクトルが各行に加算される。

## normalize_rows

### tier1
「各行の合計で割る」には、まず行ごとの合計を計算する必要がある。ただしそのままだと形状が合わずうまく割り算できないことがある。

### tier2
`matrix.sum(axis=1)` は形状 `(rows,)` になる。行列 `(rows, cols)` と割り算するには形状を `(rows, 1)` にする必要があり、そのために `keepdims=True` というオプションがある。

### tier3
```
row_sums = matrix.sum(axis=1, keepdims=True)
return matrix / ...
```

## center_columns

### tier1
「列ごとの平均を引く」は、行方向にループする必要はない。軸(axis)を指定して平均を取れば、残りは自動でブロードキャストされる。

### tier2
`matrix.mean(axis=0)` は列ごとの平均(形状 `(cols,)`)になる。これを行列から引くと自動的に各行に対して引き算される。

### tier3
`matrix - matrix.mean(axis=0)` を返す。
