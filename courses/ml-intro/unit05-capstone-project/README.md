# unit05: 総合ミニプロジェクト

このユニットを終えると、「データ読込→前処理→分割→学習→評価」の一連の流れを
組み込みデータセットに対して一人で最初から最後まで書けるようになる。
unit01〜04で個別に学んだ道具を、実務でやる形にまとめる回。

## なぜ学ぶか

実務のデータ分析は「綺麗なデータにいきなりモデルを当てる」ことはまずない。現実のデータは欠損だらけで列ごとのスケールもバラバラであり、まず**下ごしらえ(欠損補完・スケーリング)**をしてから学習・評価に進む。この「読込→前処理→分割→学習→評価」の一連の流れこそが、どんな案件でも通用する**実務の最小ワークフロー**である。ここを一人で書けることが、機械学習を「使える」水準の入口になる。求人票の「scikit-learnでのモデル構築経験」の中身は、まさにこのエンドツーエンドの流れを回せることを指す。

## 概念: パイプライン化とデータリークの回避

- unit01〜04では NumPy配列操作・pandas前処理・回帰・分類をそれぞれ個別に練習した。実務では「補完→スケーリング→学習」を毎回手作業でつなぐのではなく、`Pipeline` で1つのオブジェクトにまとめる。C#で複数の処理ステップを1つの処理チェーンに合成するのに近い。
- 前処理の統計量(平均・標準偏差など)は**学習データだけから計算**し、テストデータには適用(`transform`)するだけにする。テストデータの情報を前処理に混ぜてしまうと、本番で未知のデータを正しく扱えない(データリーク)。
- 実データには欠損がつきものだが、`load_wine` や `load_breast_cancer` は綺麗すぎるため、このユニットではシード固定の乱数で意図的に欠損を注入し、`SimpleImputer` で補完する練習をする。
