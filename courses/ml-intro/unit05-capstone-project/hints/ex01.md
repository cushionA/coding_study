## load_features

### tier1
組み込みデータセットのAPIは、特徴量と正解ラベルをまとめて返すことが多い。片方だけ欲しいときの受け取り方を思い出す。

### tier2
`load_wine(return_X_y=True)` は `(X, y)` のタプルを返す。X側だけを使う。

### tier3
```
X, _ = load_wine(return_X_y=True)
return X
```

## inject_missing

### tier1
「ランダムに一部のセルを欠損にする」は、まず配列全体と同じ形状の乱数を作り、それを閾値で真偽値マスクに変える、という2段階で考える。

### tier2
`np.random.default_rng(seed)` で生成器を作り、`rng.random(X.shape)` で0〜1の一様乱数配列を作る。その値が `missing_rate` 未満の位置が欠損対象になる。元の配列を壊さないためにまずコピーする。

### tier3
```
X_missing = X.copy().astype(float)
rng = np.random.default_rng(seed)
mask = rng.random(X.shape) < missing_rate
X_missing[mask] = np.nan
return X_missing
```

## impute_mean

### tier1
欠損補完は自分でループして平均を計算しなくても、scikit-learnに専用のtransformerがある。

### tier2
`SimpleImputer(strategy="mean")` のインスタンスを作り、`fit_transform` を欠損入り配列に対して呼ぶ。

### tier3
```
imputer = SimpleImputer(strategy="mean")
return imputer.fit_transform(X_missing)
```
