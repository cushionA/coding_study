## run_end_to_end

### tier1
この関数は新しい処理を発明する必要はない。ここまでの課題で書いた「分割」「前処理」「学習」「評価」を、正しい順番で1本につなげるだけ。

### tier2
1. `train_test_split` で分割する。
2. `build_pipeline()` で作ったPipelineを学習データに `fit_transform`、テストデータに `transform`(ex02と同じ注意点)。
3. `LogisticRegression` を変換後の学習データで `fit`。
4. `accuracy_score` でテストデータの正解率を計算する。
5. モデルと正解率をタプルで返す。

### tier3
```
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=test_size, random_state=random_state
)

pipeline = build_pipeline()
X_train_t = pipeline.fit_transform(X_train)
X_test_t = pipeline.transform(X_test)

model = LogisticRegression(max_iter=1000, random_state=random_state)
model.fit(X_train_t, y_train)

accuracy = accuracy_score(y_test, model.predict(X_test_t))
return model, accuracy
```
