# ex03_train_evaluate ヒント

## train_classifier

### tier1
分類モデルの学習は、unit04で扱った「オブジェクトを作ってfitする」という一貫した流れそのもの。

### tier2
`LogisticRegression` のインスタンスを作り、`fit(X_train, y_train)` を呼ぶ。呼んだ後のモデル自体を返せばよい(fitは内部状態を変えるだけで新しいオブジェクトは返さない)。

### tier3
```
model = LogisticRegression(max_iter=1000, random_state=random_state)
model.fit(X_train, y_train)
return model
```

## evaluate_accuracy

### tier1
「予測してから正解と比べる」という2段階の処理。まず予測結果の配列を作る。

### tier2
`model.predict(X_test)` で予測ラベルの配列を得て、`accuracy_score(正解, 予測)` に渡す。引数の順番に注意。

### tier3
```
y_pred = model.predict(X_test)
return accuracy_score(y_test, y_pred)
```

## evaluate_confusion_matrix

### tier1
正解率だけでは「どのクラスとどのクラスを間違えやすいか」が分からない。それを表形式で見るための関数がある。

### tier2
`model.predict(X_test)` の結果と `y_test` を `confusion_matrix` に渡す。

### tier3
```
y_pred = model.predict(X_test)
return confusion_matrix(y_test, y_pred)
```
