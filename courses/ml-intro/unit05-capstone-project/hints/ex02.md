# ex02_pipeline ヒント

## build_preprocess_pipeline

### tier1
複数の前処理ステップを毎回手動でつなぐ代わりに、scikit-learnには「ステップの並びをオブジェクト化する」仕組みがある。

### tier2
`Pipeline` に `(名前, transformer)` のリストを渡す。ex01で使った補完器とスケーラーを、この順番で並べる。

### tier3
```
return Pipeline([
    ("imputer", SimpleImputer(strategy=...)),
    ("scaler", StandardScaler()),
])
```

## split_data

### tier1
学習用とテスト用にデータを分ける処理は、unit03で扱った関数がそのまま使える。

### tier2
`train_test_split(X, y, test_size=..., random_state=...)` を呼ぶだけ。戻り値の順序に注意。

### tier3
```
return train_test_split(X, y, test_size=test_size, random_state=random_state)
```

## fit_transform_split

### tier1
学習データとテストデータでは、Pipelineに対する呼び方が異なる。片方は「学習しながら変換」、もう片方は「学習済みの統計量で変換だけ」。

### tier2
学習データには `fit_transform`、テストデータには `transform` を使う。テストデータの平均・標準偏差を使ってしまうと、本番で未知データを正しく扱えなくなる(リーク)。

### tier3
```
X_train_t = pipeline.fit_transform(X_train)
X_test_t = pipeline.transform(X_test)
return X_train_t, X_test_t
```
