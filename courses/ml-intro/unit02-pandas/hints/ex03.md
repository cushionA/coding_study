# ex03_missing_groupby ヒント

## count_missing

### tier1
「値が欠損しているか」を各要素ごとに判定する専用のメソッドがSeriesにある。

### tier2
`df[column].isna()` は欠損なら True になるブールのSeriesを返す。True の合計 = 欠損の個数。

### tier3
`int(df[column].isna().sum())` を返す。

## fillna_with_mean

### tier1
「欠損を埋める」専用のメソッドがある。埋める値は自分で計算して渡す。

### tier2
`df.copy()` してから、対象列に `.fillna(埋める値)` を代入する。埋める値は同じ列の `.mean()`。

### tier3
```
result = df.copy()
result[column] = result[column].fillna(result[column].mean())
return result
```

## drop_rows_with_missing

### tier1
「欠損がある行を削除する」専用のメソッドがある。対象列を絞ることもできる。

### tier2
`df.dropna(subset=...)` に列名のリストを渡すと、そのリストの列だけを見て欠損判定する。

### tier3
`df.dropna(subset=...)` に引数の列名リストを渡して返す。

## group_mean

### tier1
「グループごとに集計する」処理は、C#のLINQ `GroupBy` に相当する専用のメソッドがある。

### tier2
`df.groupby(グループ列)` でグループ化オブジェクトになる。そこから `[集計列]` を選び `.mean()` を呼ぶ。

### tier3
`df.groupby(グループ列)[集計列].mean()` の形。引数の変数名をそのまま当てはめる。

## group_agg

### tier1
group_meanと同じグループ化のあと、平均と件数を「同時に」求める方法を考える。

### tier2
groupby したSeriesに対して `.agg([...])` に複数の集計名を文字列のリストで渡すと、列ごとの結果になる。

### tier3
`df.groupby(グループ列)[集計列].agg([...])` に `"mean"` と `"count"` を含むリストを渡す。
