## inject_missing

### tier1
「ランダムに一部の行だけを欠損させる」には、まずどの行を欠損させるかをランダムに選ぶ必要がある。

### tier2
`np.random.default_rng(seed)` の `.choice(df.index, size=個数, replace=False)` で重複なくインデックスを選べる。
選んだインデックスに対して `.loc[選んだ位置, column] = np.nan` で代入する。

### tier3
```
result = df.copy()
rng = np.random.default_rng(seed)
n_missing = int(len(df) * frac)
missing_idx = rng.choice(df.index, size=n_missing, replace=False)
result.loc[missing_idx, column] = np.nan
return result
```

## clean_and_summarize

### tier1
この課題内の3つの関数(inject_missing, fillna, mean_by_species相当)を順につなげるだけ。新しいAPIは不要。

### tier2
`inject_missing` の結果に対して `.fillna(平均値)` を代入し、その結果を `mean_by_species` に渡す。

### tier3
```
missing_df = inject_missing(df, column, frac, seed=seed)
missing_df[column] = missing_df[column].fillna(missing_df[column].mean())
return mean_by_species(missing_df, column)
```
