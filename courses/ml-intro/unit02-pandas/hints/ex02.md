# ex02_filter_select ヒント

## filter_by_threshold

### tier1
「条件を満たす行だけ残す」はNumPyのブールマスクと同じ考え方が、DataFrameの行にも使える。

### tier2
`df[column] > threshold` で真偽値のSeriesができる。それを `df[...]` の添字にすると行が絞り込まれる。

### tier3
`df[df[列名] > しきい値]` の形。マスクを作ってから同じ `df` の添字に渡す。

## select_columns

### tier1
複数列を選ぶときは、1列のときと違って「リスト」を添字に渡す。

### tier2
`df[列名]` は1列(Series)、`df[列名のリスト]` は複数列(DataFrame)になる。

### tier3
`df[...]` に列名のリストをそのまま渡して返す。

## first_n_rows

### tier1
「位置」で行を取り出すための専用のアクセサがDataFrameにはある。列名は関係ない。

### tier2
`iloc` は「integer location」の略で、リストのスライスと同じ感覚で `[:n]` のように使える。

### tier3
`df.iloc[...]` に先頭からの件数を表すスライスを渡して返す。

## get_cell

### tier1
「行ラベル」と「列名」の両方を指定してセルを取るための専用のアクセサがある。

### tier2
`loc` は「ラベル」で指定するアクセサ。`df.loc[行ラベル, 列名]` の形でカンマ区切りで指定できる。

### tier3
`df.loc[...]` に行ラベルと列名をカンマ区切りで渡して返す。

## add_diff_column

### tier1
新しい列を追加するには、まだ存在しない列名に代入すればよい。ただし元のdfへの副作用に注意。

### tier2
`df.copy()` で複製を作ってから、`result[新列名] = ...` の形で列同士の演算結果を代入する。

### tier3
```
result = df.copy()
result[new_column] = result[col_a] - result[col_b]
return result
```
