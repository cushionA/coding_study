# ex02_metrics ヒント

## compute_mae

### tier1
「誤差の絶対値の平均」を自分で計算する必要はない。scikit-learnのmetricsモジュールに専用関数がある。

### tier2
`mean_absolute_error(y_true, y_pred)` を使う。

### tier3
`mean_absolute_error(y_true, y_pred)` を返す。

## compute_mse

### tier1
MAEと同様、「誤差の2乗の平均」にも専用関数がある。

### tier2
`mean_squared_error(y_true, y_pred)` を使う。

### tier3
`mean_squared_error(y_true, y_pred)` を返す。

## compute_rmse

### tier1
RMSEはMSEと無関係な指標ではない。すでに書いた関数を再利用できないか考える。

### tier2
RMSEはMSEの平方根。`compute_mse` をこの関数の中から呼び出し、`np.sqrt` で平方根を取る。

### tier3
```
return np.sqrt(compute_mse(y_true, y_pred))
```

## compute_r2

### tier1
R2(決定係数)にも専用関数がある。「1に近いほど良い、0は平均を予測するのと同等」という意味を持つ指標。

### tier2
`r2_score(y_true, y_pred)` を使う。

### tier3
`r2_score(y_true, y_pred)` を返す。

## evaluate_all

### tier1
ここまでに定義した4つの関数をそれぞれ呼び出し、結果を1つのまとまり(キーと値の対応)に詰めるだけ。

### tier2
Python の辞書リテラル `{"key": value, ...}` を使って、4つの関数の戻り値をキーごとに格納する。

### tier3
```
return {
    "mae": compute_mae(y_true, y_pred),
    "mse": compute_mse(y_true, y_pred),
    "rmse": compute_rmse(y_true, y_pred),
    "r2": compute_r2(y_true, y_pred),
}
```
