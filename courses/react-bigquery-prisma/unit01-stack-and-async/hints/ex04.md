# ex04_capstone ヒント

## fetchBooksConcurrently

### tier1
この関数は新しいロジックを作る必要がない。「idの配列」を「タスク(引数なしで
呼べてPromiseを返す関数)の配列」に変換してから、ex01で作った並行実行の
関数に渡すだけ。`ids.map(...)` で変換できる。

### tier2
`ids.map((id) => () => fetchBook(fetchFn, id))` で「idごとに fetchBook を
呼ぶ関数」の配列を作る(アロー関数を2重に書く点に注意。外側が
`runInParallel` に渡す「タスク」、内側の `fetchBook(...)` 呼び出しが
実際の処理)。できた配列を `runInParallel` に渡して return する。

### tier3
```ts
const tasks = ids.map((id) => () => fetchBook(fetchFn, id));
return runInParallel(tasks);
```

## loadBookCatalog

### tier1
3ステップ: ①`loadApiConfig()` で設定オブジェクトを取得 ②取得した設定を
使って書籍を並行取得(すでに作った `fetchBooksConcurrently` を使う)
③戻り値の組み立て。ここで重要なのは、`loadApiConfig()` が返す `apiKey`
という**文字列そのもの**を戻り値に入れてはいけないこと。戻り値には
「apiKeyが空でないかどうか」という真偽値だけを入れる。

### tier2
`const { baseUrl, apiKey } = loadApiConfig();` で分割代入する
(C#のタプル分解に近い)。`await fetchBooksConcurrently(fetchFn, bookIds)`
で books を取得する。最後に
`{ config: { baseUrl, apiKeyPresent: apiKey.length > 0 }, books }`
の形で返す。

### tier3
```ts
const { baseUrl, apiKey } = loadApiConfig();
const books = await fetchBooksConcurrently(fetchFn, bookIds);
return {
  config: { baseUrl, apiKeyPresent: apiKey.length > 0 },
  books,
};
```
