# ex01_promise_basics ヒント

## wait

### tier1
JavaScriptの `Promise` はC#の `Task` と同じで「コンストラクタに渡した処理」が
非同期の本体になる。渡す処理の中で、時間になったら「完了した」と伝える関数を
呼び出す必要がある。

### tier2
`new Promise<void>((resolve) => { ... })` の形。`resolve` はコンストラクタが
自動的に渡してくれる関数で、これを呼んだ瞬間にPromiseが完了扱いになる。
`setTimeout(関数, ミリ秒)` の中で `resolve` を呼べばよい。

### tier3
```ts
return new Promise<void>((resolve) => {
  setTimeout(() => resolve(), ms);
});
```

## doubleAfterDelay

### tier1
この関数はすでに `async` が付いている。中で `wait` を呼び、その完了を
`await` で待ってから、続きの計算をすればよい。C#の `await Task.Delay(ms);`
の直後に処理を続けるのと同じ形。

### tier2
`await wait(ms);` を1行書いてから、`n * 2` を `return` する。

### tier3
```ts
await wait(ms);
return n * 2;
```

## runInSeries

### tier1
「1件ずつ順番に」は、ループの中で毎回 `await` することで実現できる。
C#で `foreach` の中で `await task;` すると、次のループに進む前に必ず
今のタスクが終わるのと同じ。`Promise.all` はここでは使わない。

### tier2
空配列 `results` を用意し、`for (const task of tasks)` で1件ずつ
`task()` を呼んで `await` し、返ってきた値を `results` に `push` していく。
最後に `results` を返す。

### tier3
```ts
const results: number[] = [];
for (const task of tasks) {
  const value = await task();
  results.push(value);
}
return results;
```

## runInParallel

### tier1
「全部同時に」実行するには、先に全部のタスクを呼び出して Promise の配列を
作ってから、まとめて待つ必要がある。1件ずつ `await` してしまうと
`runInSeries` と同じ逐次実行になってしまう。C#の `Task.WhenAll` に相当する
機能がJavaScriptにもある。

### tier2
`tasks.map((task) => task())` で、まず全タスクを呼び出した「実行中の
Promiseの配列」を作る(この時点ではまだ何も `await` していない)。
その配列を `Promise.all(...)` に渡すと、全部が終わった時点で結果の配列を
持つ1つのPromiseになる。

### tier3
```ts
const promises = tasks.map((task) => task());
return Promise.all(promises);
```
