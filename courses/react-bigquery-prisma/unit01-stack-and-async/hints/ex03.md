# ex03_env_config ヒント

## getEnvOrDefault

### tier1
`process.env[key]` の型は `string | undefined`。「undefinedだったら
デフォルト値を使う」という処理には、if文を書かなくても済む演算子が
TypeScriptにある(C#にも同名の演算子がある)。

### tier2
`process.env[key] ?? defaultValue` の1行。`??` は左側が `null` か
`undefined` のときだけ右側を使う(空文字列 `""` はそのまま通す点に注意。
`||` だと空文字列も「falsy」として弾いてしまうので `??` を使うこと)。

### tier3
```ts
return process.env[key] ?? defaultValue;
```

## getRequiredEnv

### tier1
まず値を変数に受け取り、それが「無い」または「空」と言える2つの条件を
チェックする。どちらかに当てはまったら `Error` を `throw` する。

### tier2
`const value = process.env[key];` の後、
`if (value === undefined || value === "") { throw new Error(...); }`
のようにチェックする。最後に `value` を返す(この時点でTypeScriptは
`value` が `string` だと推論してくれるはず)。

### tier3
```ts
const value = process.env[key];
if (value === undefined || value === "") {
  throw new Error(`環境変数 ${key} が設定されていません`);
}
return value;
```

## parsePositiveIntEnv

### tier1
流れは3段: ①未設定ならdefaultValueで即return ②設定されていれば
文字列を数値に変換 ③その数値が「整数かつ0より大きいか」を検証する。
文字列→数値変換にはグローバル関数が使える。整数判定には `Number` の
静的メソッドが使える。

### tier2
`process.env[key]` が `undefined` なら `return defaultValue;`。
そうでなければ `Number(raw)` で変換し、`Number.isInteger(parsed)` と
`parsed > 0` の両方を満たさなければ `Error` を throw する。

### tier3
```ts
const raw = process.env[key];
if (raw === undefined) return defaultValue;
const parsed = Number(raw);
if (!Number.isInteger(parsed) || parsed <= 0) {
  throw new Error(`環境変数 ${key} は正の整数である必要があります`);
}
return parsed;
```

## loadApiConfig

### tier1
すでに作った3つの関数を、それぞれ1回ずつ呼んでオブジェクトにまとめるだけ。
新しいロジックはほぼ無い。どのキー名をどの関数に渡すかはコメントに書いて
ある通り。

### tier2
`getEnvOrDefault("API_BASE_URL", "http://localhost:4010")`、
`getRequiredEnv("API_KEY")`、
`parsePositiveIntEnv("API_TIMEOUT_MS", 5000)` の3つの結果を、
`ApiConfig` 型のプロパティ名(`baseUrl` / `apiKey` / `timeoutMs`)に
対応させてオブジェクトとして返す。

### tier3
```ts
return {
  baseUrl: getEnvOrDefault("API_BASE_URL", "http://localhost:4010"),
  apiKey: getRequiredEnv("API_KEY"),
  timeoutMs: parsePositiveIntEnv("API_TIMEOUT_MS", 5000),
};
```
