# ex01_props_component ヒント

## BookCard

### tier1
JSXは「HTMLに似た式」。関数コンポーネントは、propsをそのまま埋め込んだJSXを
`return`するだけでよい。ループも条件分岐もまだ不要。

### tier2
`{}` の中にJavaScript(TypeScript)の式を書くと、その値がそのまま表示される
(C#の文字列補間 `$"{author}"` に近い)。author の前に「著者: 」という文字列を
くっつけたいときは、`{}` の中で文字列同士を `+` で連結するか、
テンプレートリテラル(バッククォート文字列)`` `著者: ${author}` `` を使う。
JSXはルート要素が1つでなければならないので、複数のタグを返すときは
`<div>` などで包む。

### tier3
```tsx
export function BookCard({ title, author }: BookCardProps) {
  return (
    <div>
      <h3>{title}</h3>
      <p>著者: {/* ここに author を式として埋め込む */}</p>
    </div>
  );
}
```
