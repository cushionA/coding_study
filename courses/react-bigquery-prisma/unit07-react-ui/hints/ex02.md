# ex02_state_events ヒント

## BookStatusToggle

### tier1
「今どちらの状態か」を覚えておく箱が必要で、その箱の中身が変わると画面が
勝手に描き直される。それがReactの`useState`というフック。ボタンを押したときに
呼ばれる普通の関数(イベントハンドラ)の中で、その箱の中身を更新する。

### tier2
`const [borrowed, setBorrowed] = useState(初期値)` の形で書く。`borrowed` が
「今の値」、`setBorrowed` が「新しい値に置き換える関数」。トグル(反転)したい
ときは `setBorrowed(!borrowed)` でもよいが、「直前の値を使って次の値を決める」
場面では `setBorrowed(prev => !prev)` という関数を渡す形のほうが安全
(C#で例えるなら、古い値を直接書き換えるのではなく「次の値はこう計算してね」
という関数を渡すイメージ)。ボタンの `onClick` にそのハンドラを渡す。
初期値には `initialBorrowed` パラメータ(すでにデフォルト値`false`付きで
分割代入されている)をそのまま使う。

### tier3
```tsx
export function BookStatusToggle({ title, initialBorrowed = false }: BookStatusToggleProps) {
  const [borrowed, setBorrowed] = useState(initialBorrowed);

  function handleClick() {
    setBorrowed((prev) => /* ここでprevを反転させる */);
  }

  return (
    <div>
      <h3>{title}</h3>
      <p>{/* borrowedがtrueなら"貸出中"、falseなら"貸出可" */}</p>
      <button onClick={handleClick}>{/* borrowedに応じてラベルを出し分け */}</button>
    </div>
  );
}
```
