# ex03_list_render ヒント

## getBookKey

### tier1
「配列のindexをkeyにしてはいけない」がこの関数の存在理由。indexは
並び替えや削除で変わってしまうので、データ自体が持つ「変わらない目印」を使う。
このBook型がすでに持っているフィールドの中に、その目印になるものがある。

### tier2
Reactのkeyはstringかnumberを受け付けるが、この関数の戻り値はstringに
揃える必要がある。数値を文字列に変換する方法(`String(...)` やテンプレート
リテラル)を使う。

### tier3
```ts
export function getBookKey(book: Book): string {
  return String(book.id);
}
```

## BookList

### tier1
空配列かどうかで表示を分岐する必要がある。それ以外は「配列を変換して並べる」
という、C#のLINQ `Select` に相当する配列メソッドをJSXの中で使う。

### tier2
`books.length === 0` なら `EMPTY_MESSAGE` を表示するJSXを返す。
そうでなければ `<ul>` の中で `books.map(book => <li key={...}>...</li>)` の形で
JSX要素の配列を作り、それを `{}` で埋め込む。keyには前の関数
`getBookKey(book)` の結果を渡す。各`<li>`のテキストは
`{book.title} — {book.author}` のように、間に半角スペース+em dash+半角スペース
を挟む。

### tier3
```tsx
export function BookList({ books }: BookListProps) {
  if (books.length === 0) {
    return <p>{EMPTY_MESSAGE}</p>;
  }
  return (
    <ul>
      {books.map((book) => (
        <li key={getBookKey(book)}>
          {/* book.title} — {book.author の形で埋め込む */}
        </li>
      ))}
    </ul>
  );
}
```
