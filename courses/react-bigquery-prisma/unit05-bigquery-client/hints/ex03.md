# ex03_insert_rows ヒント

## insertRows

### tier1
BigQueryLikeが提供するメソッドをそのまま辿るだけ。
「データセットを選ぶ→その中のテーブルを選ぶ→行を渡す」という
3段階のメソッドチェーンになっている。

### tier2
`bq.dataset(datasetId)`が返すオブジェクトの`.table(tableId)`を呼び、
さらにその戻り値の`.insert(rows)`を呼ぶ。`await`を付けて結果を待つ。

### tier3
```ts
await bq.dataset(datasetId).table(tableId).insert(rows);
```

## insertRowsWithLog

### tier1
「例外をthrowする関数」を「成功/失敗を戻り値で表す関数」に変換する、
ex04(unit02)のfetchBooksSafelyと同じパターン。try/catchで包み、
catchした中身の「種類」で分岐する。

### tier2
```
try {
  await insertRows(...)
  return { ok: true, insertedCount: rows.length };
} catch (error) {
  if (error instanceof PartialFailureError) {
    ...
  }
  throw error; // 想定外のエラーは握りつぶさない
}
```
PartialFailureErrorのときは、`error.insertErrors.length`が失敗件数、
`rows.length - 失敗件数`が成功件数になる。

### tier3
```ts
try {
  await insertRows(bq, datasetId, tableId, rows);
  return { ok: true, insertedCount: rows.length };
} catch (error) {
  if (error instanceof PartialFailureError) {
    const failedCount = error.insertErrors.length;
    return {
      ok: false,
      insertedCount: rows.length - failedCount,
      failedCount,
      failures: error.insertErrors,
    };
  }
  throw error;
}
```
