# ex02_param_query ヒント

## buildCountByAuthorQuery

### tier1
「値をSQL文字列の中に埋め込む」のではなく、「SQL文字列にはプレースホルダー
の名前だけを書き、値は別のオブジェクトに入れる」のがパラメータ化クエリ。
authorという文字列がquery文字列の中に**そのまま出てきてはいけない**。

### tier2
クエリ文字列には`@author`という名前をそのまま書く(テンプレートリテラルで
`${author}`のように値を埋め込まない)。paramsには`{ author }`
(オブジェクトの短縮記法、`{ author: author }`と同じ)を渡す。

### tier3
```ts
return {
  query: "SELECT COUNT(*) AS bookCount FROM `app_analytics.books` WHERE author = @author",
  params: { author },
};
```

## buildRecentBooksQuery

### tier1
buildCountByAuthorQueryと同じ考え方を、パラメータ2個(since, limit)に
広げるだけ。LIMIT句もプレースホルダーにできる。

### tier2
クエリ文字列に`@since`と`@limit`の2箇所を置き、paramsに
`{ since: sinceTimestamp, limit }`を渡す(キー名とプレースホルダー名を
揃えること)。

### tier3
```ts
return {
  query:
    "SELECT * FROM `app_analytics.books` WHERE ingested_at >= @since ORDER BY ingested_at LIMIT @limit",
  params: { since: sinceTimestamp, limit },
};
```

## countBooksByAuthor

### tier1
すでに組み立てたクエリを`bq.query(...)`に渡すだけ。戻り値は
「行の配列」を1個だけ持つタプル(`[QueryRows]`)なので、分割代入で
最初の要素を取り出す。

### tier2
`const [rows] = await bq.query(buildCountByAuthorQuery(author));`
で1行目のQueryRowsを取り出し、`rows[0]`が存在すればその`bookCount`を、
存在しなければ`0`を返す。

### tier3
```ts
const [rows] = await bq.query(buildCountByAuthorQuery(author));
const first = rows[0];
if (!first || typeof first.bookCount !== "number") {
  return 0;
}
return first.bookCount;
```
