# ex03_upsert_relations ヒント

## upsertBookByIsbn

### tier1
「あれば更新・無ければ作成」を1回の呼び出しで済ませる専用のメソッドが
ある。名前にそのままの意味が入っている。渡すオプションは3つのキーに
分かれる: どの行を指すか / 存在した場合に何を書き換えるか / 存在
しなかった場合に何を作るか。

### tier2
`prisma.book.upsert({ where: ..., update: ..., create: ... })` の形。
`where` はisbnで1件を特定する(`{ isbn: input.isbn }`)。`update` には
isbn以外の書き換えたいフィールド、`create` にはisbnを含む全フィールドを
渡す。

### tier3
```ts
const { isbn, title, author, rating } = input;
return prisma.book.upsert({
  where: { isbn },
  update: { title, author, rating },
  create: { isbn, title, author, rating },
});
```

## addTagToBook

### tier1
「更新すると同時に、関連する別モデルの行も新しく作る」というネストした
書き込みは、`update` の `data` の中に**関連モデル名をキーとして**
書く。作った関連行を戻り値に含めたいなら、find系と同じ `include` を
一緒に渡せばよい。

### tier2
`prisma.book.update({ where: ..., data: { tags: { create: { label } } }, include: { tags: true } })`
の形。`tags: { create: {...} }` の `create` の中には `bookId` を
書かなくてよい(Prismaが「今更新している本」を自動で埋める)。

### tier3
```ts
return prisma.book.update({
  where: { id: bookId },
  data: { tags: { create: { label } } },
  include: { tags: true },
});
```

## getBookWithTags

### tier1
ex01のfindBookByIdとほぼ同じだが、関連するタグも一緒に読み込みたい。
「一緒に読み込む」ためのオプションキーが1つある(C#のEF Coreの
`Include` に相当)。

### tier2
`prisma.book.findUnique({ where: ..., include: { tags: true } })` の形。

### tier3
```ts
return prisma.book.findUnique({ where: { id: bookId }, include: { tags: true } });
```
