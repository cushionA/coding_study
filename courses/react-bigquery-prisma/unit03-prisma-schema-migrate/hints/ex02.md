# ex02_write_model ヒント

## buildFieldLine

### tier1
組み立てる要素は3つ(名前・型・属性)で、間はすべて半角スペース1つ。
`?` は型のすぐ後ろにくっつく(型の一部として扱う)。属性が無いときは
その部分を丸ごと省略する(スペースも余計に付けない)。

### tier2
`field.optional` が true なら `${field.type}?`、そうでなければ `field.type`
をそのまま使う変数(例えば `typePart`)を1つ作る。`field.attributes` は
未指定の可能性があるので `?? []` でデフォルト空配列にし、長さが0より
大きいときだけ `" " + attrs.join(" ")` を付け足す。最後に
`` `  ${field.name} ${typePart}${attrPart}` `` を返す。

### tier3
```ts
const typePart = field.optional ? `${field.type}?` : field.type;
const attrs = field.attributes ?? [];
const attrPart = attrs.length > 0 ? ` ${attrs.join(" ")}` : "";
return `  ${field.name} ${typePart}${attrPart}`;
```

## buildModelBlock

### tier1
この関数は `buildFieldLine` を各フィールドに適用してから、決まった形の
文字列でくるむだけ。1から組み立て直す必要はない。

### tier2
`fields.map(buildFieldLine)` で行の配列を作り、`.join("\n")` で改行区切りの
1本の文字列にする。それを `` `model ${modelName} {\n...\n}` `` の
テンプレートリテラルに埋め込む。

### tier3
```ts
const lines = fields.map(buildFieldLine).join("\n");
return `model ${modelName} {\n${lines}\n}`;
```

## buildIndexLine

### tier1
Prismaの `@@index([a, b])` の中身は、フィールド名をカンマ+スペースで
つないだだけの単純な文字列。C#の `string.Join(", ", names)` と同じ発想。

### tier2
`fieldNames.join(", ")` を角かっこの中に埋め込み、先頭にインデント2
スペースと `@@index([` を付け、末尾を `])` で閉じる。

### tier3
```ts
return `  @@index([${fieldNames.join(", ")}])`;
```
