# ex03_migrate_flow ヒント

## extractCreatedTableNames

### tier1
migration.sql は `-- CreateTable` のコメントの後に `CREATE TABLE "名前" (` が
続く、決まった形の素のSQL。ex01の `extractModelNames` と発想は全く同じ
(パターンをグローバルに検索してキャプチャする)。

### tier2
`sql.matchAll(/正規表現/g)` を使い、パターンは `CREATE TABLE "([^"]+)"`
(ダブルクオートの中身をキャプチャ)。各一致から `m[1]` を集める。

### tier3
```ts
const matches = sql.matchAll(/CREATE TABLE "([^"]+)"/g);
return Array.from(matches, (m) => m[1]);
```

## extractColumnNames

### tier1
提供済みの `extractCreateTableBody` がテーブル定義の中身(丸括弧の中)を
文字列で返してくれる。あとはそれを1行ずつに分け、各行の先頭にある
`"カラム名"` の部分だけを抜き出せばよい。

### tier2
`body.split("\n")` → 各行を `.trim()` → 空行を `.filter` で除去、という
下ごしらえの後、各行に対して `line.match(/^"([^"]+)"/)` で先頭の
ダブルクオート部分を取り、`?.[1]` でキャプチャした文字列だけを取り出す
(見つからない行は結果的に空文字列になるので、最後にもう一度 `.filter`
で除いておくと安全)。テーブルが見つからない場合は空配列。

### tier3
```ts
const body = extractCreateTableBody(sql, tableName);
if (!body) return [];
return body
  .split("\n")
  .map((line) => line.trim())
  .filter((line) => line.length > 0)
  .map((line) => line.match(/^"([^"]+)"/)?.[1] ?? "")
  .filter((name) => name.length > 0);
```

## isColumnNullable

### tier1
SQLiteのCREATE TABLEでは、「NOT NULL と書かれていない列は NULL 許容」
という単純なルール。目的のカラムの行を1本見つけて、その行の中に
`"NOT NULL"` という文字列があるかどうかだけを見ればよい。

### tier2
`extractCreateTableBody` で本体を取り、行に分けて `.trim()` した後、
`.find((l) => l.startsWith(\`"${columnName}"\`))` で目的の行を探す。
見つからなければ `false`。見つかったら `!line.includes("NOT NULL")` を返す。

### tier3
```ts
const body = extractCreateTableBody(sql, tableName);
if (!body) return false;
const line = body
  .split("\n")
  .map((l) => l.trim())
  .find((l) => l.startsWith(`"${columnName}"`));
if (!line) return false;
return !line.includes("NOT NULL");
```

## extractCreatedIndexNames

### tier1
`extractCreatedTableNames` と同じ発想だが、対象が
`CREATE INDEX "名前"` と `CREATE UNIQUE INDEX "名前"` の2パターンある点に
注意(UNIQUE は付いたり付かなかったりする)。

### tier2
正規表現の中で `UNIQUE ` の部分を「あってもなくてもよい」グループにする
(`(?:UNIQUE )?` のように `?` を付けたグループにする)。それ以外は
`extractCreatedTableNames` と同じ流れ。

### tier3
```ts
const matches = sql.matchAll(/CREATE (?:UNIQUE )?INDEX "([^"]+)"/g);
return Array.from(matches, (m) => m[1]);
```
