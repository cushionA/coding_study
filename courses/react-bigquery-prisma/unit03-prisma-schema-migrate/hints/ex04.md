# ex04_capstone ヒント

## createPrismaClient

### tier1
Prisma 7 のSQLiteは「ドライバアダプタ」を経由してしか接続できない。手順は
①アダプタを接続先(ファイルパス)付きで作る ②そのアダプタを渡して
PrismaClient を作る、の2段階。この2つは常にセットで、順番も決まっている。

### tier2
`new PrismaBetterSqlite3({ url: ... })` の `url` は `file:` に続けて
`dbFilePath` をそのまま埋め込む形(テンプレートリテラル)。できたアダプタ
インスタンスを `new PrismaClient({ adapter })` のオプションオブジェクトに
渡す。

### tier3
```ts
const adapter = new PrismaBetterSqlite3({ url: `file:${dbFilePath}` });
return new PrismaClient({ adapter });
```

## createBook

### tier1
生成されたPrismaClientには model 名(小文字始まり)のプロパティが生えて
おり、そこに `.create` メソッドがある。渡すオプションのキーは
「作りたいデータそのもの」を表す1語。

### tier2
`prisma.book.create({ data: ... })` の形。この関数の引数 `data` を
そのままオプションの `data` に渡せばよい。戻り値もそのまま return する。

### tier3
```ts
return prisma.book.create({ data });
```

## listBooksByAuthor

### tier1
一覧取得のメソッドと、条件を絞り込むためのオプションキーがそれぞれ
1つずつある。C#のLINQで言えば `Where` に相当する部分を、オブジェクト
リテラルで表現するのがPrismaの流儀。

### tier2
`prisma.book.findMany({ where: { author: ... } })` の形。`author` に
この関数の引数をそのまま入れる。

### tier3
```ts
return prisma.book.findMany({ where: { author } });
```
