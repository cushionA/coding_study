# ex01_read_schema ヒント

## extractModelNames

### tier1
schema.prisma はただのテキスト。`model 名前 {` という並びが何回出てくるかを
数えるだけでよい。C#の正規表現 `Regex.Matches` と同じ発想で、TypeScriptの
文字列にも「グローバルに全部の一致を取る」方法がある。

### tier2
`schema.matchAll(/正規表現/g)` を使うと、一致箇所をすべて走査できる
イテレータが返る。パターンは `model\s+(\w+)\s*\{` のように、モデル名を
かっこ `()` で捕らえる(キャプチャグループ)。各一致から `m[1]` を取り出す。

### tier3
```ts
const matches = schema.matchAll(/model\s+(\w+)\s*\{/g);
return Array.from(matches, (m) => m[1]);
```

## extractFieldNames

### tier1
この関数のためにすでに `extractModelBlock` と `fieldLinesOf` が用意されて
いる。自分で正規表現を書く必要はなく、2つの提供関数を順番に呼ぶだけ。
フィールド定義行は「フィールド名 型 属性...」の順なので、行を空白で
分割した最初の要素がフィールド名になる。

### tier2
`extractModelBlock(schema, modelName)` が `null` を返したら空配列を返す
(モデルが見つからないケース)。見つかったら `fieldLinesOf(block)` で
行の配列を取り、各行に対して `line.split(/\s+/)[0]` を適用する
(`.map` が使える、C#のLINQ `Select` と同じ)。

### tier3
```ts
const block = extractModelBlock(schema, modelName);
if (!block) return [];
return fieldLinesOf(block).map((line) => line.split(/\s+/)[0]);
```

## extractUniqueFieldNames

### tier1
`extractFieldNames` とほぼ同じ流れだが、その前に「`@unique` という文字列を
含む行だけ」に絞り込むステップが1つ増える。

### tier2
`fieldLinesOf(block)` の結果に対して、`.filter((line) => line.includes("@unique"))`
で絞り込んでから、`extractFieldNames` と同じように `.map` でフィールド名を
取り出す。モデルが見つからない場合は空配列。

### tier3
```ts
const block = extractModelBlock(schema, modelName);
if (!block) return [];
return fieldLinesOf(block)
  .filter((line) => line.includes("@unique"))
  .map((line) => line.split(/\s+/)[0]);
```

## isFieldOptional

### tier1
フィールド定義行の2番目のトークン(空白区切りの2番目)が「型」。
Prismaでは null 許容の型は末尾に `?` が付く(例: `String?`)。目的の
フィールドの行を1本見つけて、その型トークンの末尾だけ調べればよい。

### tier2
`fieldLinesOf(block)` の中から `.find((l) => l.split(/\s+/)[0] === fieldName)`
で目的の行を探す。見つからなければ `false`。見つかったら
`line.split(/\s+/)[1]` が型で、`.endsWith("?")` で判定する。

### tier3
```ts
const block = extractModelBlock(schema, modelName);
if (!block) return false;
const line = fieldLinesOf(block).find((l) => l.split(/\s+/)[0] === fieldName);
if (!line) return false;
const type = line.split(/\s+/)[1] ?? "";
return type.endsWith("?");
```
