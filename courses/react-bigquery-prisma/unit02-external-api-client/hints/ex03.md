# ex03_retry_timeout ヒント

## shouldRetry

### tier1
リトライすべきステータスは2種類だけ(「相手が一時的に忙しい」429と、
「相手側のサーバエラー」5xx台)。それ以外はすべてfalseでよい。C#の
switch式やifの連鎖と同じ発想。

### tier2
`if (status === 429) return true;` と
`if (status >= 500 && status <= 599) return true;` を並べ、
最後に `return false;` で締める。

### tier3
```ts
if (status === 429) return true;
if (status >= 500 && status <= 599) return true;
return false;
```

## computeBackoffDelay

### tier1
式は3段階: ①`base`を`attempt`回だけ倍にした値(指数関数、`2 ** attempt`)
②それを`max`で頭打ちにする(`Math.min`) ③そこにランダムな量(ジッタ)を
上乗せする。オプションが未指定のときの既定値は`??`で補う。

### tier2
```
const exponential = Math.min(base * 2 ** attempt, max);
const jitter = exponential * jitterRatio * randomFn();
```
のように「指数部分」と「ジッタ部分」を別々に計算してから足す。
最後に`Math.round(...)`で整数msに丸めて返す。

### tier3
```ts
const base = options.baseMs ?? 100;
const max = options.maxMs ?? 5000;
const jitterRatio = options.jitterRatio ?? 0.5;
const randomFn = options.randomFn ?? Math.random;
const exponential = Math.min(base * 2 ** attempt, max);
const jitter = exponential * jitterRatio * randomFn();
return Math.round(exponential + jitter);
```

## fetchWithTimeout

### tier1
C#の`CancellationTokenSource.CancelAfter`に相当する仕組みがJS標準にある
(`AbortSignal.timeout(ms)`)。fetchFnの第2引数(init)に`signal`として渡す
だけで、時間切れになると自動的にfetchFn側がエラーを投げてくれる。
このエラーには`name`プロパティがあり、タイムアウトによるものは
`"AbortError"`という決まった名前になっている。

### tier2
```
try {
  return await fetchFn(url, { signal: AbortSignal.timeout(timeoutMs) });
} catch (error) {
  ...
}
```
の形にする。catchの中で`error instanceof Error && error.name === "AbortError"`
を確認し、真なら分かりやすいメッセージのErrorを新しくthrowする。
それ以外(本当の通信エラーなど)はそのまま`throw error;`で伝える。

### tier3
```ts
try {
  return await fetchFn(url, { signal: AbortSignal.timeout(timeoutMs) });
} catch (error) {
  if (error instanceof Error && error.name === "AbortError") {
    throw new Error(`${url} が ${timeoutMs}ms でタイムアウトしました`);
  }
  throw error;
}
```

## fetchWithRetry

### tier1
`for`ループで`attempt`を0から`maxAttempts`未満まで回す。各ループの中で
「呼ぶ→成功なら返す→失敗ならリトライすべきか判定→リトライするなら待つ」
の順に処理する。すでに作った`shouldRetry`と`computeBackoffDelay`を使う。

### tier2
ループの中身のおおまかな骨格:
```
const response = await fetchFn(url);
if (response.ok) { ... jsonを返す ... }
// ここに来たら失敗。リトライすべきかどうかと、最後の試行かどうかを見る
if (!shouldRetry(response.status) || 最後の試行) { throw ... }
await sleepFn(computeBackoffDelay(attempt, options.backoff));
```
「最後の試行か」は`attempt === maxAttempts - 1`で判定できる。

### tier3
```ts
const maxAttempts = options.maxAttempts ?? 3;
const sleepFn = options.sleepFn ?? defaultSleep;

for (let attempt = 0; attempt < maxAttempts; attempt++) {
  const response = await fetchFn(url);
  if (response.ok) {
    return (await response.json()) as T;
  }
  const isLastAttempt = attempt === maxAttempts - 1;
  if (!shouldRetry(response.status) || isLastAttempt) {
    throw new Error(`... status: ${response.status}, attempts: ${attempt + 1}`);
  }
  await sleepFn(computeBackoffDelay(attempt, options.backoff));
}
throw new Error(`... attempts: ${maxAttempts}`);
```
