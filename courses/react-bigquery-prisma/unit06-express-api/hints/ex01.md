# ex01_first_route ヒント

## listBooksHandler

### tier1
Expressのハンドラは `(req, res) => {...}` の形。JSONを返すには、C#の
`return Ok(data)` に相当する専用メソッドがある。データはすでにモジュール上部の
配列として用意されている。

### tier2
`res.json(...)` を呼ぶと、渡したオブジェクト(や配列)をJSON文字列にして
Content-Typeも`application/json`に設定してくれる。ステータスコードは何も
指定しなければ200になる。返すデータはこのファイル上部の`books`配列そのもの。

### tier3
```ts
res.json(books);
```

## getBookHandler

### tier1
URLの一部(`:id`)はどんな値でも文字列として届く。数値として比較する前に
変換が必要。すでに用意されている`findBookById`ヘルパーをそのまま使えばよい。

### tier2
`req.params.id`を`Number(...)`で変換し、`findBookById(id)`を呼ぶ。結果が
`undefined`(見つからない)なら`res.status(404).json({ error: "book not found" })`
を返し、そうでなければ`res.json(book)`を返す。ステータスコードは`.json()`の前に
`.status(404)`のようにメソッドチェーンで指定する(C#の`NotFound(...)`に相当)。

### tier3
```ts
const id = Number(req.params.id);
const book = findBookById(id);
if (!book) {
  res.status(404).json({ error: "book not found" });
  return;
}
res.json(book);
```
