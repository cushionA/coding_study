# ex04_capstone ヒント

## createBookService の listBooks

### tier1
この関数は3つの作業を順番にやるだけ:全件取得→絞り込み→ページング。
絞り込みは配列から条件に合うものだけ残す操作、ページングは配列の一部分を
切り出す操作。どちらもTypeScriptの配列メソッド1つずつで書ける
(C#のLINQの`Where`と`Skip().Take()`に近い)。

### tier2
- 全件: `await repo.findAll()`
- 絞り込み: `query.q`があれば、`title`または`author`に(小文字化してから)
  含まれるものだけ`filter`で残す。`query.q`がなければ絞り込まない。
- `total`は絞り込み**後**・ページング**前**の件数(`filtered.length`)
- ページング: 開始位置は`(query.page - 1) * query.pageSize`。そこから
  `query.pageSize`件を`slice(start, start + pageSize)`で切り出す
- 戻り値は`{ items, total, page: query.page, pageSize: query.pageSize }`

### tier3
```ts
const all = await repo.findAll();
const q = query.q?.toLowerCase();
const filtered = q
  ? all.filter((b) => b.title.toLowerCase().includes(q) || b.author.toLowerCase().includes(q))
  : all;
const total = filtered.length;
const start = (query.page - 1) * query.pageSize;
const items = filtered.slice(start, start + query.pageSize);
return { items, total, page: query.page, pageSize: query.pageSize };
```

## createBookService の getBook

### tier1
`repo.findById`は見つからなければ何を返すか(型定義`BookRepository`を見る)を
確認し、その場合にどう振る舞うべきかはex03と同じ考え方(すでに用意されている
`NotFoundError`を使う)。

### tier2
`repo.findById(id)`が`null`なら`NotFoundError(\`book ${id} not found\`)`を
throwする(catchは不要。route層のasyncハンドラが自動でerrorHandlerまで
運んでくれる)。`null`でなければそのままreturnする。

### tier3
```ts
const book = await repo.findById(id);
if (!book) {
  throw new NotFoundError(`book ${id} not found`);
}
return book;
```

## GET /api/books ルート(サービス呼び出し部分)

### tier1
クエリの検証はすでに済んでいる(`parsed.data`が使える状態)。あとは
service層に処理を丸投げしてその結果をそのまま返すだけ。

### tier2
`await service.listBooks(parsed.data)`の結果を`res.json(...)`にそのまま渡す。
try/catchは書かなくてよい(Express 5がasyncハンドラの例外を自動で拾う)。

### tier3
```ts
const result = await service.listBooks(parsed.data);
res.json(result);
```

## GET /api/books/:id ルート(サービス呼び出し部分)

### tier1
idの形式チェックはすでに済んでいる。あとは`service.getBook`に投げて
その結果を返すだけ(存在しない場合の404はservice側がNotFoundErrorを
throwすることで、errorHandlerが自動で処理してくれる)。

### tier2
`await service.getBook(id)`の結果を`res.json(...)`で返す。

### tier3
```ts
const book = await service.getBook(id);
res.json(book);
```
