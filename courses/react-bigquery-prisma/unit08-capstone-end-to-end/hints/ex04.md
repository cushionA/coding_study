# ex04_capstone ヒント

## SearchPage

### tier1
これはunit07の`BookExplorer`(1つのstateで「今どの段階か」を表現し、
副作用の中で非同期処理を呼ぶ)と、ex01の`SearchBox`をそのまま組み合わせる
課題。新しく増えるのは「検索語が空文字のときはidleに戻す」という分岐と、
「読み込み中(loading)」を自分で明示的にセットするタイミングだけ。

### tier2
`useState<PageState>({ status: "idle" })`で状態を持つ。`SearchBox`に渡す
`onSearch`用の関数を1つ定義し、その中で
①`keyword === ""`なら`{ status: "idle" }`にしてreturn、
②そうでなければ`{ status: "loading" }`にしてから`searchBooks(keyword)`を
呼び、`.then`で成功時`{ status: "success", response }`、`.catch`で
失敗時`{ status: "error", message }`に遷移させる(unit07のBookExplorerと
同じ`.then`/`.catch`の書き方でよい。async関数を別に切り出してもよい)。
JSX側は`state.status`で分岐し、successのときだけさらに
`response.items.length === 0`と`response.summary === null`で分岐する。

### tier3
```tsx
export function SearchPage({ searchBooks, debounceMs = DEFAULT_DEBOUNCE_MS }: SearchPageProps) {
  const [state, setState] = useState<PageState>({ status: "idle" });

  function handleSearch(keyword: string): void {
    if (keyword === "") {
      setState({ status: /* ここ */ });
      return;
    }
    setState({ status: "loading" });
    searchBooks(keyword)
      .then((response) => setState({ status: "success", response }))
      .catch((err: unknown) => {
        const message = /* err からmessageを取り出す */;
        setState({ status: "error", message });
      });
  }

  return (
    <div>
      <SearchBox onSearch={handleSearch} debounceMs={debounceMs} />
      {state.status === "idle" && <p>{IDLE_TEXT}</p>}
      {state.status === "loading" && <p>{/* ここ */}</p>}
      {state.status === "error" && <p role="alert">エラー: {state.message}</p>}
      {state.status === "success" && (
        <>
          {state.response.items.length === 0 ? (
            <p>{NO_RESULTS_TEXT}</p>
          ) : (
            <ul>
              {state.response.items.map((book) => (
                <li key={book.id}>{book.title}</li>
              ))}
            </ul>
          )}
          {state.response.summary === null ? (
            <p>{/* ここ */}</p>
          ) : (
            <ul>{/* summaryの各要素をliで表示。keyにauthorを使うとよい */}</ul>
          )}
        </>
      )}
    </div>
  );
}
```
(テストは`vi.useFakeTimers()`+`vi.advanceTimersByTimeAsync`で
デバウンス→非同期のsearchBooks呼び出し→state更新、を一気に進めている。
`await act(async () => { await vi.advanceTimersByTimeAsync(300) })`という
書き方はunit07までには出てこなかった新しいテスト技法なので、テスト側の
コードは読むだけでよい)
