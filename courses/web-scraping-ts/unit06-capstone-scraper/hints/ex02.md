# ex02_fetch_details ヒント

## parseItemDetail

### tier1
詳細ページの各フィールドはそれぞれ専用のclassが振られた要素1個に対応している。
cheerioでパースしたあと、class名ごとに`.text()`を呼んで集めればRawItemDetailが作れる。

### tier2
`cheerio.load(detailHtml)`した`$`に対し、`.item-name`・`.item-price`などのセレクタで
それぞれ1要素を選び`.text()`を呼ぶ。`.text()`は常に`string`を返す(`.attr()`と違って
undefinedにならない)ので、加工せずそのままオブジェクトのプロパティに入れられる。

### tier3
```ts
const $ = cheerio.load(detailHtml);
return {
  name: $(".item-name").text(),
  price: $(".item-price").text(),
  // origin/roast/stock/descriptionも同じパターンで埋める
};
```

## fetchAllItemDetails

### tier1
「複数のURLを1件ずつ取得して結果を貯める」という処理は、C#で言えば
`foreach (var url in urls) { var detail = await FetchAsync(url); results.Add(detail); }`と
同じ形。順序を保つ必要があるので`Promise.all`で並列に取ってから並べ替える必要はない
(単純な`for...of` + `await`で順番通りになる)。

### tier2
空配列の`for...of`ループは0回実行されるだけなので、空配列を渡したときの分岐処理は
特に書かなくてよい。

### tier3
```ts
const details: RawItemDetail[] = [];
for (const url of itemUrls) {
  const html = await fetchLocal(url);
  // parseItemDetailの結果をdetailsに追加
}
return details;
```
