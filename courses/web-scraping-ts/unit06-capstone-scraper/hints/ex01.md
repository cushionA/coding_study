# ex01_collect_links ヒント

## extractItemLinks

### tier1
一覧ページには複数の商品リンクが並んでいる。cheerioで対象のセレクタに一致する要素を
すべて取り出し、それぞれのhref属性をBASE_URLと連結すれば完成する。

### tier2
`cheerio.load(listHtml)`でパースした`$`に対して、複数要素を対象にした`.each((_, el) => ...)`
でループする(単一要素の`.attr()`だと最初の1件しか取れない)。`$(el).attr("href")`は
`string | undefined`を返すので、undefinedのときは配列に加えないようガードする。

### tier3
```ts
const $ = cheerio.load(listHtml);
const links: string[] = [];
$("a.product-link").each((_, el) => {
  const href = $(el).attr("href");
  // ここでhrefがundefinedでないかを確認してからlinksに追加する
});
return links;
```

## extractNextPageUrl

### tier1
「次ページへのリンク」は一覧ページに0個か1個しかない。存在確認は`.length`や
`.attr()`の戻り値がundefinedかどうかで判定できる。

### tier2
class名で1件だけ選択し、`.attr("href")`がundefinedならnullを、あればBASE_URLと
連結した文字列を返す。三項演算子や`??`が使える。

### tier3
```ts
const $ = cheerio.load(listHtml);
const href = $("a.next-page").attr("href");
// hrefがあればBASE_URL + href、無ければnullを返す
```

## collectAllItemLinks

### tier1
「次ページがある間はループを続ける」という構造は、C#の`while (url != null) { ... }`と
同じ形になる。1回のループで「現在のページを取得→リンクを集める→次ページURLを取得して
currentUrlを更新」の3ステップを行う。

### tier2
ループの終了条件は`extractNextPageUrl`が`null`を返すこと。集めたリンクは配列の
`push(...spread)`でまとめて追加できる。`fetchLocal`は非同期関数なので`await`を忘れないこと。

### tier3
```ts
const allLinks: string[] = [];
let currentUrl: string | null = startUrl;
while (currentUrl !== null) {
  const html = await fetchLocal(currentUrl);
  // extractItemLinksの結果をallLinksに追加
  // extractNextPageUrlの結果でcurrentUrlを更新
}
return allLinks;
```
