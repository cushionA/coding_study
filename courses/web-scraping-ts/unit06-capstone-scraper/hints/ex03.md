# ex03_pipeline_integrate ヒント

## stripLabel

### tier1
「ラベル: 値」の形をした文字列から値だけを取り出すには、最初のコロンの位置を見つけて
そこから右側を切り出せばよい。コロンが無いケースの扱いも忘れずに。

### tier2
`String.prototype.indexOf(":")`はコロンが無ければ`-1`を返す。見つかった位置+1から
`.slice()`で右側を切り出し、前後の空白は`.trim()`で除去する。

### tier3
```ts
const idx = text.indexOf(":");
if (idx === -1) {
  // コロンが無い場合の戻り値
}
// idx+1から右側を切り出してtrimしたものを返す
```

## priceToNumber

### tier1
"1200円"から数値だけを残すには、数字以外の文字を全部取り除いてから数値に変換すればよい。
正規表現の文字クラスと否定(`^`)が使える。

### tier2
`.replace(/[^0-9]/g, "")`で数字以外を空文字に置き換え、`Number(...)`で変換する。

### tier3
```ts
const digitsOnly = priceText.replace(/[^0-9]/g, "");
return Number(digitsOnly);
```

## cleanItem

### tier1
生のオブジェクトの各フィールドに、上で作った`stripLabel`/`priceToNumber`を適材適所で
かけていくだけ。nameとstockはラベル形式ではないのでそのまま使う。

### tier2
priceは`priceToNumber`、originとroastは`stripLabel`を通す。descriptionとname、stockは
加工不要。idは引数でもらった値をそのまま入れる。

### tier3
```ts
return {
  id,
  name: rawItem.name,
  price: priceToNumber(rawItem.price),
  origin: stripLabel(rawItem.origin),
  // roast/stock/descriptionも同じ要領で埋める
};
```

## writeCatalogCsv

### tier1
CSVは「ヘッダ行+データ行」を改行でつないだ単なるテキストファイル。各行は
カンマ区切りの値の並びだが、値そのものにカンマ・改行・ダブルクォートが含まれる場合は
その値全体をダブルクォートで囲み、内部のダブルクォートは2つ重ねてエスケープする
(RFC4180というCSVの標準的なルール)。

### tier2
ヘッダ用のキー配列(id/name/price/...の順)を1つ定義し、ヘッダ行とデータ各行を
同じキー配列を使って組み立てると列の順序がぶれない。エスケープ判定は
「カンマ・改行・ダブルクォートのいずれかを含むか」を`.includes()`で調べる。
最後に`fs.writeFileSync(outputPath, 文字列, "utf-8")`で書き出す。

### tier3
```ts
const headers = ["id", "name", "price", "origin", "roast", "stock", "description"] as const;

function escapeField(value: string | number): string {
  const str = String(value);
  // str がカンマ/改行/ダブルクォートを含む場合、"..."で囲みつつ内部の"を""に置換
  return str;
}

const lines = [headers.join(",")];
// rowsの各行をheaders順にescapeFieldしてカンマ結合し、linesに追加
fs.writeFileSync(outputPath, lines.join("\n") + "\n", "utf-8");
```
