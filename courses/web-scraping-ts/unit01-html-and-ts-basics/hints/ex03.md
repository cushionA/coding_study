# ex03_html_skim ヒント

## extractBetween

### tier1
「あるタグの直後から次のタグの直前まで」を取り出すには、開始位置と終了位置をそれぞれ探して
文字列を切り出す。C#の `IndexOf` + 部分文字列取得に近い操作がTypeScriptの文字列にもある。

### tier2
`.indexOf(部分文字列)` は見つかった位置(インデックス)を返し、見つからなければ `-1` を返す。まず `startTag` の位置を探し、それより後ろで `endTag` の位置を探す(`.indexOf` の第2引数で検索開始位置を指定できる)。両方の位置から `.slice(a, b)` で切り出す。

### tier3
```ts
let startIdx = html.indexOf(startTag);
if (startIdx === -1) return null;
startIdx += startTag.length;
const endIdx = html.indexOf(endTag, startIdx);
if (endIdx === -1) return null;
return html.slice(startIdx, endIdx);
```

## extractHrefList

### tier1
1件だけなら extractBetween に似た発想で取れるが、複数件を集めるには「見つけたら次の検索を
そこから先で再開する」というループが必要になる。

### tier2
`'href="'` を探す位置を毎回ずらしながら `.indexOf(marker, searchFrom)` をループで呼ぶ。見つかった位置から次の `"` までがURL。ループを抜ける条件は `.indexOf` が `-1` を返したとき。

### tier3
```ts
const hrefs: string[] = [];
const marker = 'href="';
let searchFrom = 0;
while (true) {
  let startIdx = html.indexOf(marker, searchFrom);
  if (startIdx === -1) break;
  startIdx += marker.length;
  const endIdx = html.indexOf('"', startIdx);
  if (endIdx === -1) break;
  hrefs.push(html.slice(startIdx, endIdx));
  searchFrom = endIdx + 1;
}
return hrefs;
```

## extractParagraphs

### tier1
extractHrefList とほぼ同じ「ループで繰り返し検索」の構造。`<p>` と `</p>` のペアを1組ずつ
順番に探していく。

### tier2
`<p>` の開始位置を探し、そこから `</p>` の位置を探して中身を切り出す。切り出したら検索位置を `</p>` の後ろに進めて次のループへ。

### tier3
```ts
const paragraphs: string[] = [];
let searchFrom = 0;
while (true) {
  let startIdx = html.indexOf("<p>", searchFrom);
  if (startIdx === -1) break;
  startIdx += "<p>".length;
  const endIdx = html.indexOf("</p>", startIdx);
  if (endIdx === -1) break;
  paragraphs.push(html.slice(startIdx, endIdx));
  searchFrom = endIdx + "</p>".length;
}
return paragraphs;
```
