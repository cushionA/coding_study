# ex01_string_extract ヒント

## cleanWhitespace

### tier1
文字列の前後の余分な空白・改行を取り除く専用のメソッドが文字列型には最初から生えている。
C#の `string.Trim()` と同じ立ち位置。

### tier2
文字列オブジェクトの `.trim()` メソッドを使う。引数なしで前後の空白・改行をまとめて除去できる。

### tier3
`text.trim()` を返す。1行で完結する。

## splitTags

### tier1
「カンマで分割」と「各要素の前後空白を除く」は別々の操作。2段階に分けて考える。
C#の `Split` の後に `.Select(s => s.Trim())` するのと同じ流れ。

### tier2
文字列の `.split(",")` で配列になる。その配列の各要素に `.trim()` を適用する部分は、配列の `.map()`(C#の `Select`)で1行にまとめられる。

### tier3
```ts
return text.split(",").map((part) => part.trim());
```

## extractValue

### tier1
「ラベル: 値」形式の文字列を分割する際、値の中に区切り文字と同じ文字が含まれていても
壊れないようにするには、最初の1個目のコロンだけで区切る必要がある。

### tier2
`.split(":")` は全てのコロンで区切ってしまうので、そのままでは値側にコロンがあると崩れる。分割結果の配列の「先頭要素(ラベル)」と「残り全部(値、コロンが混じっていても良い)」を分けて考え、残りを再度 `":"` で `.join()` してから `.trim()` する。

### tier3
```ts
const [, ...rest] = text.split(":");
return rest.join(":").trim();
```

## formatSummary

### tier1
複数の変数を埋め込んだ文字列を組み立てるには、C#の文字列補間 `$"..."` に相当する構文がTypeScriptにもある。

### tier2
バッククォート `` ` `` で囲んだテンプレートリテラルの中に `${変数名}` を書くと、その場で値が埋め込まれる。

### tier3
`` `名前: ${name} / 職業: ${job}` `` を返す。
