# ex02_array_record ヒント

## longWordsUpper

### tier1
「条件を満たす要素だけを変換する」は、ループを書かなくても配列メソッドの連結で1行で書ける。
C#の `.Where().Select()` の連結にそのまま対応する。

### tier2
`.filter(条件関数)`(C#の `Where`)で「5文字以上」を絞り込み、続けて `.map(変換関数)`(C#の `Select`)で大文字化する。文字列の長さは `.length`、大文字化は `.toUpperCase()`。

### tier3
```ts
return words.filter((w) => w.length >= ...).map((w) => w.toUpperCase());
```
`...` には「5文字以上」を表す比較式を入れる。

## countTags

### tier1
出現回数を数えるには、「タグ名 → 回数」の対応を保持する入れ物が必要。C#の `Dictionary<string, int>` に相当するのがTypeScriptの `Record<string, number>`。

### tier2
空の `Record<string, number>` を用意し、タグを1つずつ見ながら「まだキーがなければ0として扱い、1を足す」を繰り返す。存在しないキーへのアクセスは `undefined` になるので、`??`(Null合体演算子。C#の `??` と同じ)でデフォルト値と組み合わせる。

### tier3
```ts
const counts: Record<string, number> = {};
for (const tag of tags) {
  counts[tag] = (counts[tag] ?? ...) + 1;
}
return counts;
```
`...` にはデフォルト値を入れる。

## mostCommonTag

### tier1
Recordの項目(キーと値のペア)を「値の大きい順、同点はキーの昇順」で並べ替えれば、most番目を取り出すだけで済む。

### tier2
`Object.entries(record)` で `[キー, 値]` のペアの配列が取れる。それを `.sort(比較関数)` に渡し、比較関数の中で「値が違えば値の降順、同じならキーの昇順」を判定する。文字列の大小比較は `<` / `>` がそのまま使える(C#の `string.CompareTo` に近い動きだが記号で書ける)。

### tier3
```ts
const ordered = Object.entries(counts).sort(([keyA, countA], [keyB, countB]) => {
  if (countA !== countB) return countB - countA;
  return keyA < keyB ? -1 : keyA > keyB ? 1 : 0;
});
return ordered[most - 1][0];
```
most は1始まりなのでインデックスは1つずらす。

## uniqueTags

### tier1
「値が1のキーだけ」を集めるのは longWordsUpper と同じ「条件を満たす要素だけ抽出」の発想。仕上げに並び替えが必要な点だけ異なる。

### tier2
`Object.entries(counts)` を `.filter()` で絞り込み、`.map()` でキーだけの配列にする。最後に `.sort()`(引数なしで文字コード順に並ぶ)で並べる。

### tier3
```ts
return Object.entries(counts)
  .filter(([, count]) => count === ...)
  .map(([tag]) => tag)
  .sort();
```
`...` には「ユニーク」を表す条件を入れる。
