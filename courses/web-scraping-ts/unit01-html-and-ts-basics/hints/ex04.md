# ex04_capstone ヒント

## parseProfile

### tier1
name/job/tagsの3つの行はどれも「ラベル: 値」の形をしているので、まず該当行のテキストを
タグに挟まれた部分として取り出し、それぞれからコロン以降の値を取り出す、という2段階の処理に
分解できる。tagsだけはさらにカンマ分割が必要。

### tier2
このファイル内の `extractBetween` でHTML中の該当行を取り出し、`extractValue` でラベル部分を除いた値にする。tagsの値はさらに `splitTags` に通して配列化する。3つの結果をProfileオブジェクトにまとめて返す。`extractBetween` は見つからない場合 `null` を返すので、そのまま `extractValue` に渡すと型エラーになる点に注意(`?? ""` などでフォールバックする)。

### tier3
```ts
const nameLine = extractBetween(html, 'class="name">', "</h2>") ?? "";
const jobLine = extractBetween(html, 'class="job">', "</p>") ?? "";
const tagsLine = extractBetween(html, 'class="tags">', "</p>") ?? "";

const name = extractValue(...);
const job = extractValue(...);
const tags = splitTags(extractValue(...));

return { name, job, tags };
```

## aggregateTagCounts

### tier1
複数人分のタグを「1つの大きなタグの配列」にまとめてしまえば、あとはこのファイルにある
タグ集計用のヘルパーがそのまま使える。

### tier2
配列の配列(各プロフィールの `tags`)を1段階平坦化して1つの配列にするメソッドが配列にはある(C#の `SelectMany` に相当)。平坦化した配列を `countTags` に渡す。

### tier3
```ts
const allTags = profiles.flatMap((profile) => profile.tags);
return countTags(allTags);
```

## formatProfileLine

### tier1
オブジェクトからname/job/tagsを取り出し、tagsは配列なので表示用に1つの文字列へ結合してから
全体をテンプレートリテラルで組み立てる。

### tier2
配列をカンマ区切りの文字列に戻すには `.join(", ")` を使う(C#の `string.Join` と同じ)。結合した文字列と `profile.name` / `profile.job` をテンプレートリテラルに埋め込む。

### tier3
```ts
const tagsStr = profile.tags.join(", ");
return `${profile.name}(${profile.job}) - タグ: ${tagsStr}`;
```
