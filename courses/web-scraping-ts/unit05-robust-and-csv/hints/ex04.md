# ex04_capstone ヒント

## extractRawRecords

### tier1
「1行ずつ処理する」のはcheerioの `.each()`(unit02で扱った、C#の `foreach` に
相当するもの)。各行の中でさらに `.find()` を使ってセルを絞り込む「入れ子の
探索」になる。値はこの段階ではまだ生のテキストのままでよい(trimや数値化は
しない)。

### tier2
`cheerio.load(html)` で `$` を得る。`$("tr.record").each((_, el) => {...})`
で各行を回し、コールバックの中で `$(el)` としてその行のCheerioオブジェクトを
作り直してから `.find(".name").text()` のように4つのクラス名でセルの
テキストを取り出す。取り出した4つの値をRawRecordの形にして配列に `push` する。

### tier3
```ts
const $ = cheerio.load(html);
const records: RawRecord[] = [];
$("tr.record").each((_, el) => {
  const row = $(el);
  records.push({
    name: row.find(".name").text(),
    price: row.find(".price").text(),
    stock: row.find(".stock").text(),
    date: row.find(".date").text(),
  });
});
return records;
```

## buildCsvFromDirtyHtml

### tier1
このファイル冒頭で定義済みの `parsers` オブジェクトと、ex01〜ex03で作った
3つの関数をこの順番でつなぐだけのパイプライン: 抽出 → クレンジング+スキップ →
CSV文字列化。`CleanRecord`(ex02)と`CsvRecord`(ex03)はフィールド構成が同じ
なので、TypeScriptの構造的型付けにより変換なしでそのまま渡せる。

### tier2
`extractRawRecords(html)` でRawRecordの配列を作り、それを
`cleanAllRecords(raws, parsers)` に渡してクレンジング+不正行スキップ済みの
配列を得る。最後にその配列を `recordsToCsv(...)` に渡した結果をそのまま返す。

### tier3
```ts
const raws = extractRawRecords(html);
const cleaned = cleanAllRecords(raws, parsers);
return recordsToCsv(cleaned);
```
