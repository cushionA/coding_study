# ex01_clean_fields ヒント

## cleanText

### tier1
`.trim()` は半角空白・改行は取り除くが、全角スペース(U+3000)は「空白」として
扱ってくれない場合がある。文字列の先頭と末尾を対象にした置換で対応する。

### tier2
正規表現の `.replace(/pattern/g, "")` を使い、先頭 `^[\s　]+` と末尾 `[\s　]+$` に
マッチする空白(半角の `\s` と全角スペース `　` の両方)を空文字に置き換える。`|` で
2つのパターンを1回の replace にまとめられる。

### tier3
```ts
return text.replace(/^[\s　]+|[\s　]+$/g, "");
```

## parsePriceYen

### tier1
「円マーク・カンマ・円という漢字・空白」をすべて取り除いてから残った文字列を
数値に変換する、という2段階で考える。この関数内で cleanText を再利用してよい。

### tier2
正規表現の文字クラス `[¥￥,円\s　]` にマッチする文字を全部 `.replace(..., "")` で
除去する。除去した結果が空文字なら `NaN` を返す(空文字を `Number()` に渡すと `0` に
なってしまい、C#の `int.TryParse("")` が false になるのと違う挙動になるため、
自分で弾く必要がある)。それ以外は `Number(...)` の戻り値をそのまま返せばよい
(数値化できない文字列を渡すと `Number` 自身が `NaN` を返してくれる)。

### tier3
```ts
const normalized = cleanText(text).replace(/[¥￥,円\s　]/g, "");
if (normalized === "") return NaN;
return Number(normalized);
```

## parseStock

### tier1
在庫数はカンマや通貨記号が付かない分 parsePriceYen よりシンプル。空白を除いて
Number化するだけで良いが、空文字や `"-"` のような非数値のケアが要る。

### tier2
`cleanText` で前後空白を除いた後、空文字なら `NaN` を返す。それ以外は
`Number(...)` に渡す(`"-"` のような数字にならない文字列は `Number` が自動で
`NaN` を返す)。

### tier3
```ts
const normalized = cleanText(text);
if (normalized === "") return NaN;
return Number(normalized);
```

## normalizeDate

### tier1
区切り文字が `/` `.` `-` のどれであっても、3つの数字(年・月・日)に分解できれば
あとは同じ処理でよい。正規表現の文字クラスで複数の区切り文字を1回の split で
まとめて扱える。

### tier2
`.split(/[/.\-]/)` で年・月・日の3要素に分割する(正規表現の文字クラス内では `.`
はただのピリオド、`-` は最後に置くかエスケープすれば安全)。月・日それぞれの
文字列を2桁になるよう `.padStart(2, "0")`(C#の `ToString("D2")` に近い)で
ゼロ埋めしてから、テンプレートリテラルで `"YYYY-MM-DD"` に組み立てる。

### tier3
```ts
const [year, month, day] = cleanText(text).split(/[/.\-]/);
return `${year}-${month.padStart(2, "0")}-${day.padStart(2, "0")}`;
```
