# ex03_write_csv ヒント

## escapeCsvField

### tier1
「クォートが必要かどうかの判定」と「実際にクォートする処理」を分けて考える。
判定には正規表現で「カンマ・改行・ダブルクォートのどれかが含まれるか」を
1回でチェックできる。

### tier2
`/[",\n\r]/.test(value)` で対象文字が含まれるか真偽値を得る。含まれなければ
`value` をそのまま返す。含まれる場合は、まずフィールド内の `"` を全部 `""`
に置換(`.replace(/"/g, '""')`)してから、その結果をダブルクォートで
挟んだテンプレートリテラルにする。

### tier3
```ts
const needsQuote = /[",\n\r]/.test(value);
if (!needsQuote) return value;
return `"${value.replace(/"/g, '""')}"`;
```

## recordsToCsv

### tier1
「ヘッダ行」と「データ行の配列」をまず別々に組み立て、最後にすべての行を
改行区切りで1本の文字列に連結する、という順番で考えるとやりやすい。
数値フィールドも `String(...)` で文字列化してから `escapeCsvField` に通す。

### tier2
ヘッダは `["name", "price", "stock", "date"].join(",")`。各レコードは
`escapeCsvField` を通した4つの文字列を配列にして `.join(",")` する。
ヘッダ行+全データ行を1つの配列にまとめ、`.map((line) => line + "\n")` して
から `.join("")` すれば、各行の末尾に改行が付いた1本の文字列になる。

### tier3
```ts
const header = ["name", "price", "stock", "date"];
const lines = [header.join(",")];
for (const record of records) {
  const fields = [
    escapeCsvField(record.name),
    escapeCsvField(String(record.price)),
    escapeCsvField(String(record.stock)),
    escapeCsvField(record.date),
  ];
  lines.push(fields.join(","));
}
return lines.map((line) => `${line}\n`).join("");
```

## writeCsvFile

### tier1
CSV文字列を組み立てる部分はすでに `recordsToCsv` があるので、この関数は
「文字列を作って、ファイルに書く」の2行で終わる薄いラッパー。

### tier2
`recordsToCsv(records)` で文字列を作り、`fs.writeFileSync(filePath, csv, "utf-8")`
でファイルに書き出す(第3引数の `"utf-8"` を忘れると環境依存のエンコーディングに
なりうるので明示する)。

### tier3
```ts
const csv = recordsToCsv(records);
fs.writeFileSync(filePath, csv, "utf-8");
```
