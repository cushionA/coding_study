# ex02_error_handling ヒント

## computeBackoffMs

### tier1
「指数バックオフ」は試行回数(attempt)が増えるたびに待ち時間を2倍・4倍・8倍…と
増やす部分、「ジッタ」はそこに毎回異なる小さなランダム値を足す部分。この2つを
別々に計算してから足し合わせる。

### tier2
指数部分は `baseMs * Math.pow(2, attempt)`(TSでは `**` 演算子でも書ける)。
ジッタ部分は `randomFn()` が返す0以上1未満の値に `baseMs` を掛けて
「0〜baseMs未満のランダムな追加時間」にする。2つを足して返す。

### tier3
```ts
const exponential = baseMs * 2 ** attempt;
const jitter = randomFn() * baseMs;
return exponential + jitter;
```

## withRetry

### tier1
「試して、失敗したら待って、また試す」を `maxRetries + 1` 回まで繰り返すループ。
C#の `for` + `try/catch` の中で例外を握りつぶして次のループへ進む形に近いが、
最後まで失敗し続けた場合だけは例外を外に投げ直す必要がある。

### tier2
`for (let attempt = 0; attempt <= maxRetries; attempt++)` のループの中で
`try { return await fn(); }` する。`catch` に入ったら例外を変数に保存しておき、
`attempt < maxRetries` のとき(=まだ再試行の余地があるとき)だけ
`computeBackoffMs` で待ち時間を計算して `sleepFn` を `await` する。ループを
最後まで抜けたら、保存しておいた例外を `throw` する。

### tier3
```ts
let lastError: unknown;
for (let attempt = 0; attempt <= maxRetries; attempt++) {
  try {
    return await fn();
  } catch (err) {
    lastError = err;
    if (attempt < maxRetries) {
      await sleepFn(computeBackoffMs(attempt, baseMs, randomFn));
    }
  }
}
throw lastError;
```

## cleanOneRecord

### tier1
4つのフィールドをそれぞれ対応するparser関数に通してから、変換結果が
「空文字」や「NaN」になっていないかをチェックする2段階の処理。異常があれば
`throw new Error(...)` で呼び出し元に知らせる(C#で `throw new InvalidOperationException(...)`
するのと同じ発想)。

### tier2
`parsers.parseName(raw.name)` などで4つとも変換してから、
`name === ""` / `Number.isNaN(price)` / `Number.isNaN(stock)` のいずれかが
真なら、状況が分かるメッセージ付きで `Error` を投げる。全部OKならオブジェクトに
まとめて `return` する。

### tier3
```ts
const name = parsers.parseName(raw.name);
const price = parsers.parsePrice(raw.price);
const stock = parsers.parseStock(raw.stock);
const date = parsers.parseDate(raw.date);

if (name === "") throw new Error(`商品名が空です: ${JSON.stringify(raw)}`);
if (Number.isNaN(price)) throw new Error(`価格が不正です: ${raw.price}`);
if (Number.isNaN(stock)) throw new Error(`在庫数が不正です: ${raw.stock}`);

return { name, price, stock, date };
```

## cleanAllRecords

### tier1
1件ずつ `cleanOneRecord` に通し、例外が飛んできたらその行だけ諦めて次に進む。
C#の `foreach` の中で `try/catch` して `catch` 節でログを出し `continue` する
のとまったく同じ構造。

### tier2
結果を貯める配列を用意し、`for...of` で各rawを回す。`try` の中で
`cleanOneRecord` の結果を配列に `push`、`catch` の中では
`console.warn(...)` でメッセージを出すだけ(何もpushしない=スキップ)。

### tier3
```ts
const results: CleanRecord[] = [];
for (const raw of raws) {
  try {
    results.push(cleanOneRecord(raw, parsers));
  } catch (err) {
    console.warn(`スキップ: ${(err as Error).message}`);
  }
}
return results;
```
