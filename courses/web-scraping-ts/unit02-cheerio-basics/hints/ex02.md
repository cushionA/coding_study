# ex02_each_loop ヒント

## collectNavLabels

### tier1
複数マッチする要素を1件ずつ処理して配列にまとめるのは、C#の
`foreach (var el in list) { result.Add(...); }` と同じ形。cheerioでは
`.each()` に「1件ずつ呼ばれるコールバック関数」を渡す。

### tier2
空配列を用意し、`$(".nav-link").each((index, element) => { ... })` の中で
`$(element)` と包み直してから `.text()` を呼び、配列に `push` する。
コールバックの第1引数(インデックス)は使わないなら `_i` のように
アンダースコア始まりの名前にしてよい。

### tier3
```ts
const $ = cheerio.load(html);
const labels: string[] = [];
$(".nav-link").each((_i, el) => {
  labels.push($(el).text());
});
return labels;
```

## firstNavLabel

### tier1
「最初の1件だけ」欲しいときは `.each()` でループを回さなくても、
最初の1件だけを返す専用メソッドがある。要素が無い場合の判定には
コレクションの件数を使う。

### tier2
`.first()` は最初の1件のコレクションを返す(0件なら空のコレクション)。
`.length` で件数を確認できる(0なら要素が無い)。0でなければ `.text()` を返す。

### tier3
```ts
const $ = cheerio.load(html);
const first = $(".nav-link").first();
if (first.length === 0) return null;
return first.text();
```

## navLabelAt

### tier1
firstNavLabel とほぼ同じ形だが、「n番目」を取るための専用メソッドを使う。

### tier2
`.eq(index)` は0始まりのインデックスでn番目の要素を取る(範囲外なら
0件のコレクションになる)。`.length` で存在確認してから `.text()` を返す。

### tier3
```ts
const $ = cheerio.load(html);
const target = $(".nav-link").eq(index);
if (target.length === 0) return null;
return target.text();
```
