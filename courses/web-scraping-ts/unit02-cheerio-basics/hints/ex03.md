# ex03_attributes ヒント

## collectNavHrefs

### tier1
ex02の `collectNavLabels` と同じ「.each()で配列に集める」形だが、
取り出すのがテキストではなく属性値になる。

### tier2
`.each()` の中で `$(el)` と包み直してから `.attr("href")` を呼ぶ。
nav-linkには必ずhrefが付いている前提なので `??` は無くても動くが、
型は `string | undefined` なので配列の型に合わせて空文字列にフォールバック
させておくと安全。

### tier3
```ts
const $ = cheerio.load(html);
const hrefs: string[] = [];
$(".nav-link").each((_i, el) => {
  hrefs.push($(el).attr("href") ?? "");
});
return hrefs;
```

## collectSnsPlatforms

### tier1
collectNavHrefs とほぼ同じ形だが、属性が付いていない要素があるという
前提が違う。「無ければデフォルト値」の演算子がここで主役になる。

### tier2
`.attr("data-platform")` は付いていなければ `undefined` を返す。
`??`(Null合体演算子。C#の `??` と同じ)で `"unknown"` にフォールバックしながら
配列に集める。

### tier3
```ts
const $ = cheerio.load(html);
const platforms: string[] = [];
$(".sns-link").each((_i, el) => {
  platforms.push($(el).attr("data-platform") ?? "unknown");
});
return platforms;
```

## firstAttr

### tier1
firstNavLabel(ex02)と同じ「最初の1件の存在確認」の形に、属性取得と
undefined→nullの変換を組み合わせる。

### tier2
`$(selector).first()` の `.length` が0なら要素自体が無いのでnull。
要素があっても `.attr(attrName)` が `undefined` を返す場合があるので、
`??` で `null` に変換してから返す(この関数はundefinedではなくnullで
統一する、という仕様に注意)。

### tier3
```ts
const $ = cheerio.load(html);
const first = $(selector).first();
if (first.length === 0) return null;
return first.attr(attrName) ?? null;
```
