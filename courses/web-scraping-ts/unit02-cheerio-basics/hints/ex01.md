# ex01_query_basic ヒント

## loadHtml

### tier1
cheerioが提供する「HTML文字列をパースしてクエリ関数を作る」関数を、そのまま
呼び出すだけで済む。lessonの概念1で見た手順そのもの。

### tier2
`cheerio.load(html)` はパース済みのクエリ関数 `$` を返す。この関数をそのまま
呼び出し元に返せばよい。

### tier3
```ts
return cheerio.load(html);
```

## getText

### tier1
`$` に渡されたセレクタで要素を探し、その中のテキストを取り出すメソッドを
1回呼ぶだけでよい。要素が無くても例外にはならず空文字列になる。

### tier2
`$(selector)` はセレクタにマッチする要素のコレクションを返す。そこから
`.text()` を呼べばテキストが取れる(存在しなければ `""`)。

### tier3
```ts
return $(selector).text();
```

## getPostTitle / getPostMeta

### tier1
この2つは「HTMLを読み込んでから、特定のクラス名でテキストを取る」という
同じ形。上で作った `loadHtml` と `getText` を組み合わせるだけで書ける。

### tier2
`loadHtml(html)` で `$` を作り、`getText($, ".対象クラス名")` に渡して結果を
そのまま返す。2行で書ける。

### tier3
```ts
export function getPostTitle(html: string): string {
  const $ = loadHtml(html);
  return getText($, ".post-title");
}
```
`getPostMeta` は対象クラス名を `.post-meta` に変えるだけで同じ形。
