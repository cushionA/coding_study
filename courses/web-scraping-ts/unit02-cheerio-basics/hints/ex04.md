# ex04_capstone ヒント

## parseFloors

### tier1
「同じクラス名が複数箇所で繰り返される」構造では、$()でグローバルに
探すと「どのフロアに属するセクションか」の対応が失われる。まず外側の
`.floor` を1件ずつ `.each()` で処理し、その中でさらに `.find()` を使って
スコープを絞ったセレクタで探す、という二重構造にする。

### tier2
外側の `.each()` の中で `$(floorEl)` と包み直し、`.find(".floor-name")`
でその floor 内だけの名前を取る。続けて `.find(".section")` でその floor
内のセクション要素を集め、さらにその中を `.each()` で回して
`.find(".section-name")` でテキストを取り、配列に集める。最後に
`{ name, sections }` をfloorsの配列にpushする。

### tier3
```ts
const $ = cheerio.load(html);
const floors: FloorInfo[] = [];
$(".floor").each((_i, floorEl) => {
  const $floor = $(floorEl);
  const name = $floor.find(".floor-name").text();
  const sections: string[] = [];
  $floor.find(".section").each((_j, sectionEl) => {
    sections.push($(sectionEl).find(".section-name").text());
  });
  floors.push({ name, sections });
});
return floors;
```

## countTotalSections

### tier1
オブジェクト配列の中の配列プロパティの長さを全部足すのは、C#のLINQ
`.Sum(f => f.Sections.Count)` に相当する集計。配列メソッドの1つで
1行で書ける。

### tier2
`.reduce((合計, floor) => 合計 + floor.sections.length, 初期値0)` で
畳み込む。ループで `for...of` + 変数加算でも同じ結果になる。

### tier3
```ts
return floors.reduce((sum, floor) => sum + floor.sections.length, 0);
```

## formatFloorLine

### tier1
配列を表示用の文字列に変換してからテンプレートリテラルに埋め込む形は
unit01の `formatProfileLine` と同じ。空配列のときだけ特別な文字列にする
分岐が1つ増える。

### tier2
`floor.sections.length === 0` なら `"(なし)"`、そうでなければ
`.join(", ")` で結合した文字列を使う。三項演算子か if 文のどちらでもよい。
最後に `${floor.name}: ${...}` の形でテンプレートリテラルに埋め込む。

### tier3
```ts
const sectionsStr = floor.sections.length === 0 ? "(なし)" : floor.sections.join(", ");
return `${floor.name}: ${sectionsStr}`;
```
