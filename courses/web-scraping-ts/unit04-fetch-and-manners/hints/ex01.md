# ex01_handle_response ヒント

## getBodyIfOk

### tier1
成功したかどうかを表す真偽値のプロパティが response にある。それを条件分岐に使い、
本文を取り出す部分は非同期(Promiseを返す)であることを忘れない。

### tier2
`response.ok` が真のとき `await response.text()`、偽のとき `null` を返す。関数自体が
`async` なので、内部で `await` してよい。

### tier3
```ts
if (!response.ok) return null;
return await response.text();
```

## getContentType

### tier1
Headers風のオブジェクトから「なければデフォルト値」で安全に取り出したい。C#の
`TryGetValue` のように「見つからなければ既定値」というパターンを思い出す。

### tier2
`response.headers.get("Content-Type")` は無ければ `null` を返す(`undefined` ではない)。
`null` のときにデフォルト値を使うにはNull合体演算子 `??` が使える。

### tier3
```ts
return response.headers.get("Content-Type") ?? "unknown";
```

## countByStatus

### tier1
unit01で書いたような「出現回数を数えるRecord」と同じパターン。数えたいのは
各responseの `status` の値。

### tier2
空のRecordから始め、各responseの `status` をキーに `counts[key] = (counts[key] ?? 0) + 1`
で加算していく。

### tier3
```ts
const counts: Record<number, number> = {};
for (const response of responses) {
  counts[response.status] = (counts[response.status] ?? 0) + 1;
}
return counts;
```

## getBodyOrThrow

### tier1
「失敗なら例外を投げる」処理をまず書き、その後で本文を返す。C#の
`EnsureSuccessStatusCode()` に相当する処理を自分でifとthrowで書くイメージ。

### tier2
`response.ok` が偽なら `throw new ResponseError(response.status)`。真なら
`await response.text()` を返す。

### tier3
```ts
if (!response.ok) throw new ResponseError(response.status);
return await response.text();
```
