# ex02_robots_parser ヒント

## parseRobotsTxt

### tier1
robots.txtは「行の羅列」として上から順に読み進める必要がある。今どのUser-agentの
グループを読んでいるかを覚えておく変数(状態)が要る。行ごとにキーと値に分けて、
キーの種類で処理を振り分ける。

### tier2
`text.split("\n")` で行の配列にし、各行を `.trim()` してから `":"` で1回だけ分割する
(値側にコロンが含まれる可能性を考えるなら unit01の `extractValue` と同じ考え方)。
キーを小文字化して比較する。`"user-agent"` が来たら現在のUser-agent名を更新し、
`rules` にまだそのエントリが無ければ空のルール(`disallow: []`, `allow: []`,
`crawlDelay: null`)を作って `set` する。`"disallow"` / `"allow"` はその配列に
`push`、`"crawl-delay"` は `Number(value)` を `crawlDelay` に代入する。

### tier3
```ts
const rules: RobotsRules = new Map();
let currentAgent: string | null = null;

for (const rawLine of text.split("\n")) {
  const line = rawLine.trim();
  if (line === "" || !line.includes(":")) continue;

  const [rawKey, ...rest] = line.split(":");
  const key = rawKey.trim().toLowerCase();
  const value = rest.join(":").trim();

  if (key === "user-agent") {
    currentAgent = value;
    if (!rules.has(currentAgent)) {
      rules.set(currentAgent, { disallow: [], allow: [], crawlDelay: null });
    }
    continue;
  }

  if (currentAgent === null) continue;
  const rule = rules.get(currentAgent)!;

  if (key === "disallow") rule.disallow.push(value);
  else if (key === "allow") rule.allow.push(value);
  else if (key === "crawl-delay") rule.crawlDelay = Number(value);
}

return rules;
```

## canFetch

### tier1
指定したUser-Agentのルールが無ければ `"*"` にフォールバックする。ルール自体が
無ければ許可。あるパスに対して disallow と allow の両方に前方一致するエントリが
あるとき、**より長く一致した方**が優先される、という一般的なrobots.txtの解釈に従う。

### tier2
`rules.get(userAgent) ?? rules.get("*")` でルールを決める。
`rule.disallow` と `rule.allow` それぞれを走査し、`path.startsWith(entry)` を満たす
エントリの中で最長のものを探す。最終的に「最長一致がallow由来かdisallow由来か」で
結果を決める(同じ長さならallow優先、というルールにしておくと単純)。

### tier3
```ts
const rule = rules.get(userAgent) ?? rules.get("*");
if (!rule) return true;

let bestLength = -1;
let bestIsAllow = true;

for (const entry of rule.disallow) {
  if (entry !== "" && path.startsWith(entry) && entry.length > bestLength) {
    bestLength = entry.length;
    bestIsAllow = false;
  }
}
for (const entry of rule.allow) {
  if (entry !== "" && path.startsWith(entry) && entry.length >= bestLength) {
    bestLength = entry.length;
    bestIsAllow = true;
  }
}
return bestIsAllow;
```

## getCrawlDelay

### tier1
`canFetch` と同じフォールバック手順(userAgent → なければ"*")でルールを決めてから、
`crawlDelay` が指定されているかどうかを見る。

### tier2
ルールが見つからない、または `crawlDelay` が `null` なら `defaultDelay` を返す。
それ以外はルールの `crawlDelay` をそのまま返す。

### tier3
```ts
const rule = rules.get(userAgent) ?? rules.get("*");
if (!rule || rule.crawlDelay === null) return defaultDelay;
return rule.crawlDelay;
```
