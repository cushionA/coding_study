# ex04_capstone ヒント

## parseProducts

### tier1
1件のdiv.itemから複数のフィールド(名前・価格・在庫)を取り出す処理を、全div.itemに対して繰り返す。価格は文字列のままだと計算に使えないので数値に変換する必要がある。

### tier2
`$("div.item")`を`.map((_, el) => ...)`で1件ずつ処理する。各要素の中で`.find(".name").text()`、`.find(".price").text()`を取り、価格は`Number(...)`で数値化する。在庫は`.attr("data-stock")`が`"in"`と等しいかを`===`で比較すればboolean値が得られる(属性が無い場合`undefined === "in"`は自動的に`false`になる)。最後に`.get()`で配列化する。

### tier3
```ts
const $ = cheerio.load(html);
return $("div.item").map((_, el) => {
  const name = $(el).find(".name").text();
  const price = Number($(el).find(".price").text());
  const inStock = $(el).attr("data-stock") === "in";
  return { name, price, inStock };
}).get();
```

## inStockSortedByPrice

### tier1
「条件で絞り込んでから並べ替える」という、ex01のlongWordsUpperに似た「filter→処理」の流れ。並べ替えの比較は数値なので引き算で書ける。

### tier2
`.filter((p) => p.inStock)`で在庫ありだけに絞り、続けて`.sort((a, b) => a.price - b.price)`で価格の昇順に並べる(数値比較は引き算で「小さい方を前」にできる)。

### tier3
```ts
return products.filter((p) => p.inStock).sort((a, b) => a.price - b.price);
```

## priceSummary

### tier1
合計はループまたはreduceで足し込み、平均は合計を件数で割るだけ。ただし件数が0のときに割り算するとNaNになるので、先に0件かどうかをチェックしておく必要がある。

### tier2
まず`products.length === 0`なら`{ total: 0, average: 0 }`を早期returnする。それ以外は`.reduce((sum, p) => sum + p.price, 0)`で合計を求め、`Math.round(total / products.length)`で四捨五入した平均を出す。

### tier3
```ts
if (products.length === 0) return { total: 0, average: 0 };
const total = products.reduce((sum, p) => sum + p.price, 0);
const average = Math.round(total / products.length);
return { total, average };
```
