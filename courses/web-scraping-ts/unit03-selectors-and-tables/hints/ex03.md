# ex03_records_cleanup ヒント

## toEventRecord

### tier1
「要素が存在しない」場合と「要素はあるが中身が空」場合の両方を「不明」として扱いたい。cheerioで存在しない要素を探しても例外は起きず、長さ0の集合が返るだけなので、その長さで判定できる。

### tier2
`$(el).find(".title")`の戻り値の`.length`が`0`なら「そもそも要素が無い」。`.length`が`0`でなくても`.text()`が`""`なら「要素はあるが空」。この2つのどちらかに該当するときだけ`"不明"`にする(`||`で2条件をつなげる)。dateも同じ判定を繰り返す。

### tier3
```ts
const titleEl = $(el).find(".title");
const dateEl = $(el).find(".date");
const title = titleEl.length === 0 || titleEl.text() === "" ? "不明" : titleEl.text();
const date = dateEl.length === 0 || dateEl.text() === "" ? "不明" : dateEl.text();
return { title, date };
```

## parseEvents

### tier1
class名が揺れている(event / event-item)ので、1つのセレクタで両方を同時に選ぶ方法が要る。選んだ後は1件ずつ`toEventRecord`に渡すだけ。

### tier2
CSSセレクタはカンマ区切りで複数パターンを1つの文字列にまとめられる(`"li.event, li.event-item"`のように書くと「どちらかにマッチする要素」を選べる)。あとは`.map((_, el) => toEventRecord($, el))`で変換し`.get()`で配列化する。

### tier3
```ts
const $ = cheerio.load(html);
return $("li.event, li.event-item").map((_, el) => toEventRecord($, el)).get();
```

## sortedKnownDates

### tier1
「不明を除外」と「昇順に並べる」の2段階の処理。除外は条件で絞り込むだけ、並べ替えは文字列としての大小比較でよい(YYYY-MM-DD形式は文字列比較がそのまま日付の前後関係と一致する)。

### tier2
`.filter((e) => e.date !== "不明")`で不明を除外し、続けて`.sort((a, b) => ...)`で比較関数を書く。文字列の大小比較は`<`/`>`がそのまま使えるので、`a.date < b.date`なら`-1`、`a.date > b.date`なら`1`、それ以外は`0`を返す比較関数にする。

### tier3
```ts
return events
  .filter((e) => e.date !== "不明")
  .sort((a, b) => (a.date < b.date ? -1 : a.date > b.date ? 1 : 0));
```
