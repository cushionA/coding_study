# ex01_css_select ヒント

## extractProductNames

### tier1
複数の要素を一括で取り出すには、CSSセレクタ文字列を工夫して「欲しい要素だけに一致する条件」を`$()`に渡す。今回は「div.itemの直接の子であるspan.name」という親子関係が手がかりになる。

### tier2
`cheerio.load(html)`で`$`を作り、`$("div.item > span.name")`のように`>`(子供結合子)を使うと「子孫すべて」ではなく「直接の子」だけに絞れる。取得したCheerio集合はテキストの配列に変換したいので、`.map((i, el) => $(el).text())`のあとに`.get()`を呼ぶと普通の配列になる。

### tier3
```ts
const $ = cheerio.load(html);
return $("div.item > span.name").map((_, el) => $(el).text()).get();
```

## extractInStockNames

### tier1
特定の属性を持つ要素だけに絞り込みたいときは、CSSの属性セレクタが使える。class名の絞り込みと組み合わせられる。

### tier2
属性セレクタは`[属性名="値"]`という書き方をセレクタ文字列の中に埋め込める。`div.item[data-stock="in"]`のように書けば「data-stock属性がinのdiv.item」だけに絞れる。そこからさらに`span.name`を探す。

### tier3
```ts
const $ = cheerio.load(html);
return $('div.item[data-stock="in"] span.name').map((_, el) => $(el).text()).get();
```

## extractTagLabels

### tier1
extractProductNamesと同じ「セレクタで選んでテキストの配列にする」パターンをそのまま使える。今回は要素名とclassの組み合わせだけでよい。

### tier2
`a.tag`は「class="tag"を持つaタグ」を意味するセレクタ。extractProductNamesと同じ`.map().get()`の型で書ける。

### tier3
```ts
const $ = cheerio.load(html);
return $("a.tag").map((_, el) => $(el).text()).get();
```
