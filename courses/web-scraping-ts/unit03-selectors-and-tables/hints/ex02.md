# ex02_table_parse ヒント

## extractHeaders

### tier1
見出し行はthead内のth要素として決まった場所にあるので、子孫セレクタでth要素だけをまとめて取り出せばよい。

### tier2
`$("table thead th")`でth要素の集合が取れる。テキストに変換するときは前後の空白がついている場合があるので`.trim()`しておくと安全(HTMLの整形上の改行やインデントが混ざることがある)。

### tier3
```ts
const $ = cheerio.load(html);
return $("table thead th").map((_, el) => $(el).text().trim()).get();
```

## extractRows

### tier1
行ごとの処理が必要なので、まずtr要素を1つずつ取り出し(`.each()`または`.map()`)、それぞれの中でさらにtd要素を探す、という「二段階の探索」になる。

### tier2
外側は`$("table tbody tr")`。ここで注意が必要なのは、cheerioの`.map()`は中のコールバックが配列を返すとその配列を1段階平坦化してしまう(jQueryの`.map()`と同じ仕様)ので、2次元配列を作りたい今回はそのまま`.map()`を使うと1次元にフラット化されてしまう。外側は`.toArray()`で普通のJS配列に変換してから、普通の`Array.prototype.map`を使う。内側は`$(tr).find("td")`として「そのtr要素の子孫にあるtd」だけに絞り込んでから`.map().get()`でテキスト配列にする。

### tier3
```ts
const $ = cheerio.load(html);
return $("table tbody tr").toArray().map((tr) => {
  return $(tr).find("td").map((_i, td) => $(td).text().trim()).get();
});
```

## zipToRecords

### tier1
「見出しの配列」と「1行分の値の配列」を同じインデックスで対応づければ、キーと値のペアが作れる。これをすべての行に対して繰り返す。

### tier2
`rows.map((row) => ...)`で行ごとに処理する。各行の中で空のRecordを用意し、`headers.forEach((header, i) => ...)`でヘッダーの位置`i`に対応する`row[i]`を`record[header]`に入れる。列数が足りない行はその位置の代入をスキップすればよい(`i < row.length`で判定)。

### tier3
```ts
return rows.map((row) => {
  const record: Record<string, string> = {};
  headers.forEach((header, i) => {
    if (i < row.length) {
      record[header] = row[i];
    }
  });
  return record;
});
```

## parseStatsTable

### tier1
すでに作った3つの関数(見出し取得・行取得・Record変換)をこの順番でつなぐだけでよい。新しいロジックは不要。

### tier2
`extractHeaders(html)`と`extractRows(html)`をそれぞれ呼び、その結果を`zipToRecords`に渡す。

### tier3
```ts
const headers = extractHeaders(html);
const rows = extractRows(html);
return zipToRecords(headers, rows);
```
