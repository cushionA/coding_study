# lesson.ipynb テンプレート(「一緒にやる」層)

各ユニット直下の `lesson.ipynb`。演習(.py)の**前に**学習者が通る、教える本体。ライブラリを何も知らない人が README → lesson → 演習の順で進めば自力で演習を解ける状態になることが完成条件。

## 全体構造

```
[セル1] md   タイトル+このレッスンで作れるようになるもの+所要時間
[セル2] code セットアップ: import + check() ヘルパー定義(下記固定コード)
--- 以下、概念ごとに1ブロック(1ユニット3〜5概念) ---
[md]   ① なぜ: この概念が実務のどこで使われるか(2〜4文、具体的な仕事の場面)
[md]   ② 解説: 概念の説明。C#アナロジー+最小の構文説明。
        API名には必ず「何をするものか」を添える。コード例は次のセルで見せるので文中は最小限
[code] ③ 見る(worked example): 完成コードを実行して結果を見る。
        サブゴールラベル方式でコメントを付ける:
          # GOAL: このセルで分かること(1行)
          # STEP 1: <ステップ名> — 何をしているか
          (研究で習熟度向上・脱落率低減が実証されている形式)
[md]   ④ 予測: 「次のセルを実行する前に、結果がどうなるか予測して」+ 変化させた条件
[code] ⑤ 変えてみる: ③のコードの一部パラメータを変えたもの。実行して予測と照合
[md]   ⑥ 書いてみる指示: 何を書くか(③⑤より一歩だけ新しい要素を含む小さな課題)
[code] ⑦ 書いてみる: `# ここに書く` セル。ヒントコメント1行(tier1相当)まで
[code] ⑧ チェックポイント: check() で⑦の結果を即時採点(下記パターン)
--- 概念ブロック繰り返し ---
[md]   振り返りセル(自己評価+TIL): 「以下に1〜2文で書いてみよう」
        - 今日学んだことを自分の言葉で:
        - 難しかったこと(あれば):
        (チューターがセッション終了時にこの記述を学習ノートとスキルレベル判定に使う)
[md]   まとめ: 学んだ概念の一覧(1行ずつ)+この内容が**後のどのユニット/実務で使われるか**の先読みリンク
        +「演習(ex01〜)へ進もう。lessonを見ながらでOK」
```

## 固定コード(セル2に必ず含める)

```python
def check(name, actual, expected, hint=""):
    import numpy as _np
    try:
        ok = actual is not None and bool(_np.all(_np.isclose(_np.asarray(actual, dtype=float), _np.asarray(expected, dtype=float))))
    except (TypeError, ValueError):
        ok = actual == expected
    if ok:
        print(f"[OK] {name}: 正解!")
    else:
        print(f"[NG] {name}: 期待値 {expected!r} / 実際 {actual!r}")
        if hint:
            print(f"     ヒント: {hint}")
    return ok
```

(未記入(None)や型違いでも**例外で止まらず** [NG]+ヒントを出すこと — 学習者のnotebookが途中で死なないのが最優先)

(course の内容に応じて DataFrame 比較などの check 亜種を追加してよい。メッセージは必ず「期待値/実際+ヒント」を出す — 学習者が自力で直せる情報を返すのが目的)

## 品質規約

- **説明密度**: 新しいAPI・構文はすべて初出時に説明する。「知っている前提」で書いてよいのは C# の基本概念と前ユニットまでの内容のみ。目安: コード1行につき説明2〜3行まで(それ以上必要なら概念を分割する)。
- **概念を孤立させない**: 各概念ブロックの①で実務シーン、まとめで「後のユニット○○で使う」の先読みを必ず書く(転移学習のため)。
- ③のworked exampleは**必ず実行可能**で、出力を見て理解が深まるもの(printで中間状態を見せる等)。
- ④の予測質問は答えをmdに書かない(⑤を実行すれば分かる)。
- ⑦は3〜8行で書ける分量。⑧のチェックポイントは学習者が⑦を書くまで NG が出る状態で置く。
- ⑦のセルは `# ここに書く` の下に変数名だけ用意しておく(チェックセルが参照する変数を明示)。
- セル総数の目安: 3概念 × 8セル + 前後 = 25〜45セル。lesson全体で15〜25分。
- 禁止: 解答をコメントで書く、チェックセルに解答ロジックを埋め込んで逆算可能にする(期待値はリテラルで書く)。

## 生成方法

nbformat で生成する(JSONを手書きしない):

```python
import nbformat as nbf
nb = nbf.v4.new_notebook()
nb.cells = [
    nbf.v4.new_markdown_cell("# unit01 レッスン: ..."),
    nbf.v4.new_code_cell("import numpy as np\n..."),
]
nb.metadata["kernelspec"] = {"name": "python3", "display_name": "Python 3", "language": "python"}
nbf.write(nb, "courses/<course>/<unit>/lesson.ipynb")
```

生成後の検証(必須): `jupyter nbconvert` は使わず、**⑦のセルに解答を仮置きした状態で全セルを順に実行して全チェックポイントが [OK] になること**、および素の状態で実行して(⑦未記入でも)③⑤がエラーなく動き⑧が [NG] を出すことを、`nbclient` またはセル内容を抽出したスクリプト実行で確認する。
