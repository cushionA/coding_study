# unit01: NumPy配列の基本

このユニットを終えると、ループを書かずに配列全体への数値演算ができるようになる。
これは pandas・scikit-learn すべての土台になる。

## 概念: NumPy配列とC#配列の違い

- C#の `int[]` は要素ごとにループで処理するが、NumPy配列は `arr * 2` のように**配列全体への演算**が基本。内部はC実装なのでループより桁違いに速い。
- 型は全要素で共通(`dtype`)。C#のジェネリクス `T[]` に近く、`List<object>` 的な混在はしない。
