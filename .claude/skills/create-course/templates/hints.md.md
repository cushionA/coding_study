# ヒントファイルテンプレート

書式規約:
- ファイル名: `hints/exNN.md`(スケルトンと同じ連番)。1ファイルに全関数分のヒントを課題単位でまとめる。
- 必ず tier1 → tier2 → tier3 の3段階。チューターは該当tierのセクションだけを読む。
- tier1: 概念の示唆。答えに直結する API 名は出さない。「何を考えるべきか」だけ。
- tier2: 方針と使う API の方向付け。関数名やメソッド名を出してよいが、完全な呼び出し形は書かない。
- tier3: ほぼ解答。構造とAPIの使い方を具体的に示すが、**そのままコピペで通るコードは書かない**(引数名を変える、一部を「…」にする等)。
- tier1 の時点で解けるのが理想(7割の学習者が tier1 で解ける難度調整)。

```markdown
# ex01_arrays ヒント

## make_range

### tier1
連番の配列を「ループで詰める」必要はない。NumPyには範囲から配列を作る関数がある。
C#で `Enumerable.Range` を使うのと同じ発想。

### tier2
`np.arange(start, stop)` を使う。`stop` は結果に**含まれない**(C#の `Range(start, count)` とは引数の意味が違う)ので、1〜nを作るには stop をどうすべきか考える。

### tier3
`np.arange(1, x + 1)` の形。x はこの関数の引数。

## double_all

### tier1
NumPy配列にはループなしで全要素に演算を適用する仕組みがある(ブロードキャスト)。

### tier2
配列とスカラーの `*` 演算は全要素に適用される。`return` 一行で書ける。

### tier3
`arr * 2` をそのまま返す。元の配列は変更されない(新しい配列が返る)。
```
